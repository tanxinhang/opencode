我建议**先做第 1 项：(R_T\Rightarrow\Delta T_{\max}) 的理论链补全**，然后第 2 项可行性区域，最后才是 toy-grade 外推。

原因很明确：现在 FRIDS-v2 的性能、部署性和算法选择已经基本收敛，再继续优化数值收益很容易重新进入循环；真正缺少的是一句能够站得住的理论回答：

> **为什么一个基于 reliable-information service 的分布式 primal-dual scheduler，会在最终的序贯检测时延上接近可行边界？**

目前 (\Gamma\in[0.75,1]) 是很好的实验事实，但还不是这个问题的理论答案。

------

# 一、下一步不要直接“证明 (R_T\Rightarrow\Delta T)”——先拆成两个可证明定理

直接从 mirror-descent regret 跳到 stopping time，数学上跨度太大，很容易得到一个形式漂亮但实际不成立的界。

我建议拆成：

[
\boxed{
\text{FRIDS}
\rightarrow
\text{累计可靠信息服务}
}
]

和

[
\boxed{
\text{累计可靠信息服务}
\rightarrow
\text{序贯检测时延}
}
]

最后再组合。

这才严谨。

------

## 1. 第一座桥：Reliable Service → Sequential Delay

这是目前最值得先证明的部分。

对目标 (q)，令实际通信后 LLR 增量为

# [ Z_{q,t}

\log
\frac{
P_{1,q,t}^{\rm final}(Y_t)
}{
P_{0,q,t}^{\rm final}(Y_t)
}.
]

由于 (g_{iq}) 本来就是最终 observable kernel 的 KL，因此在当前主线独立证据假设下：

# [ E_1[Z_{q,t}\mid\mathcal F_{t-1}]

\sum_i x_{iq,t}g_{iq,t}.
]

定义累计 predictable reliable service：

# [ A_q(t)

\sum_{\tau=1}^{t}
\sum_i x_{iq,\tau}g_{iq,\tau}.
]

于是 LLR 可以严格分解成：

# [ \boxed{ L_q(t)

L_q(0)
+
A_q(t)
+
M_q(t)
}
]

其中

[
M_q(t)
]

是一个鞅。

这一式非常重要。

它第一次把：

[
\text{FRIDS 的 }g
]

和

[
\text{真实 sequential LLR}
]

直接接起来。

------

# 二、这里其实有很好的数学条件：LLR 增量是有界的

当前证据经过：

[
\text{quantization}
\rightarrow
\text{BSC}
\rightarrow
\text{erasure},
]

所以最终 observable alphabet 是离散有限的。

因此通常可以得到

[
|Z_{q,t}-E[Z_{q,t}\mid\mathcal F_{t-1}]|
\le b_q.
]

这意味着不用假设高斯。

可以直接利用 martingale concentration，例如 Freedman 型界。

如果

# [ V_q(t)

\sum_{\tau\le t}
\operatorname{Var}
(
Z_{q,\tau}\mid\mathcal F_{\tau-1}
),
]

那么可以得到类似：

[
P\left(
M_q(t)\le-\eta
\right)
\lesssim
\exp
\left[
-\frac{\eta^2}
{2(V_q(t)+b_q\eta/3)}
\right].
]

这里非常符合当前系统：

- 不修改通信模型；
- 不修改感知模型；
- 不引入 Gaussian shortcut；
- 直接从 post-communication LLR kernel 出发。

------

# 三、于是可以第一次得到“信息服务不足导致延迟”的正式关系

设 H1 上检测阈值为 (A_q^\star)，当前距离为：

# [ D_q

A_q^\star-L_q(0).
]

如果某个时间 (t) 已经满足：

[
A_q(t)
\ge
D_q+\eta,
]

但目标仍然没有成功越过 H1 阈值，那么必然需要发生较大的负鞅偏差。

因此可以争取得到：

[
\boxed{
P_1(T_q>t)
\le
\beta_q
+
\exp
\left[
-\frac{
(A_q(t)-D_q)^2
}{
2(V_q(t)+b_q(A_q(t)-D_q)/3)
}
\right]
}
]

具体常数还要正式推导，**这里是目标结构，不应直接当成已经证明的定理**。

其中 (\beta_q) 用来处理 H1 下错误撞到下边界的事件。

这个结果比

[
T\approx D/g
]

高一个理论层次。

因为它同时包含：

[
\boxed{
\text{mean information}
+
\text{LLR fluctuation}
+
\text{error constraint}
}
]

------

# 四、这也顺便回答了前面“finite-threshold FRIDS 要不要上线”

如果上述分析最后发现：

[
V_q(t),\quad b_q
]

造成的有限阈值修正非常小，那么：

[
\boxed{\text{不要改 FRIDS-v2}}
]

反而可以证明为什么只使用 (g) 就够了。

这是很漂亮的结果。

反过来，如果 correction 显著，再研究 finite-threshold FRIDS。

所以现在**不要先改算法**。

先通过理论把剩余误差的来源搞清楚。

------

# 五、第二座桥才是：Mirror-Descent Regret → Reliable Service

当前已经有：

# [ R_T

O(\sqrt{T\log Q}).
]

但这里必须非常谨慎：

> **普通 dual regret 不能直接推出每个目标的 detection delay。**

这是目前理论上最容易写错的地方。

因为：

[
R_T\text{ small}
]

并不自动意味着

[
A_q^{FRIDS}(T)
\approx
A_q^\star(T)
\quad\forall q.
]

需要借助 FRIDS 对应的 min-max saddle structure。

------

## 正确方向是先证明 time-average service guarantee

定义归一化服务：

# [ r_q(t)

\frac{
\sum_i x_{iq,t}g_{iq,t}
}{
D_q(t)+\epsilon
}.
]

理论 relaxation 是：

[
\max_x\min_q r_q.
]

如果 primal 每周期对当前 dual price 做 best response，而 dual 用 mirror descent，那么应该争取得到：

## [ \boxed{ \min_q \frac1T \sum_{t=1}^{T}r_q^{FRIDS}(t) \ge z_T^\star

\epsilon_T
}
]

其中：

# [ \epsilon_T

O\left(
\sqrt{\frac{\log Q}{T}}
\right)
]

在静态情况下成立。

这一层才是 Theorem 4.96 真正应该升级的方向。

------

# 六、但部署算法有 (K) 个 local dual，而理论 LP 只有一个 global dual

这个问题不能藏掉。

G9A 已经告诉我们：

- local/global actions 差异很大；
- 但 delay 只差约 1.8%。

因此正式理论中可以考虑增加一个 distributed-information error：

[
\varepsilon_{\rm loc}(T).
]

得到类似：

## [ \min_q \bar r_q^{FRIDS} \ge z^\star

## \underbrace{\frac{R_T}{T}}_{\text{online regret}}

\underbrace{\varepsilon_{\rm loc}}_{\text{distributed information loss}}.
]

这就比强行宣称 local mirror descent 等价于 centralized dual 严谨得多。

而且 G9A 可以为

[
\varepsilon_{\rm loc}
]

提供实验意义上的边界支撑。

------

# 七、最终真正希望得到的定理长什么样

如果前两部分能够闭合，最后才组合。

理想结果不是：

[
T\le D/g.
]

而是类似：

[
\boxed{
E_1[T_{\max}^{FRIDS}]
\le
T_{\rm relax}^{\star}
+
\frac{
C_1R_T
+
C_2E_{\rm loc}
+
C_3\sqrt{V_T\log(Q/\delta)}
+
C_4\kappa
}{
\underline C
}
}
]

其中：

- (R_T)：调度 regret；
- (E_{\rm loc})：严格分布式 local-information penalty；
- (V_T)：LLR stochastic fluctuation；
- (\kappa)：threshold overshoot；
- (\underline C)：瓶颈目标附近最小有效 reliable-information service。

再次强调：

> **这是建议追求的 theorem shape，目前不能当成已有结论。**

如果能得到这样一个哪怕稍微保守的结果，FRIDS 理论的完整性会明显上一个层级。

------

# 八、如果时变信道要纳入，不要发明 mobility-aware FRIDS

直接把理论升级成 dynamic regret。

设每周期 relaxation optimum 为

[
y_t^\star,
]

定义路径变化：

# [ V_T^y

\sum_{t=2}^{T}
|y_t^\star-y_{t-1}^\star|_1.
]

那么可以争取：

# [ R_T^{dyn}

O
\left(
\sqrt{T\log Q}
+
V_T^y
\right).
]

这样：

- mobility；
- channel variation；
- target difficulty variation；

都通过

[
V_T^y
]

进入理论。

而不是再分别造：

- mobility-FRIDS；
- channel-aware FRIDS；
- dynamic-FRIDS。

这正好避免重新发散。

------

# 九、给这项理论设一个“生死门”

这一步非常重要，否则理论也会无限扩展。

我建议理论桥只允许三种结论。

### Case A：能得到有意义且量纲正确的 delay bound

保留。

这会成为论文最核心的理论提升之一。

------

### Case B：只能得到非常松的形式界

例如最终界：

[
\Delta T\gg T
]

在实际参数下完全无信息。

那么不要为了“有 theorem”硬写。

退回：

[
\text{feasibility law}
+
\text{empirical }\Gamma
]

作为边界解释。

------

### Case C：local-dual / stochastic stopping 使直接 bridge 无法严谨闭合

那么把理论拆开：

**Theorem A**

[
\text{cumulative reliable service}
\Rightarrow
\text{stopping-time tail bound};
]

**Theorem B**

[
\text{FRIDS}
\Rightarrow
\text{normalized-service regret}.
]

不强行写：

[
R_T\Rightarrow\Delta T
]

的一步式结果。

这仍然是很扎实的理论贡献。

------

# 十、第二优先级：可行性区域扎实化

完成理论桥之后，我建议立即做这个，而不是再优化算法。

G12-B 当前：

[
{
\text{feasible}:12,,
\text{communication}:8,,
\text{coordination}:0,,
\text{sensing}:0
}.
]

这意味着分类框架已经工作，但区域没有被完整激活。

下一步不需要改模型，只扩大物理轴。

推荐做三个 **2D slice**，不要一下做五维大扫描：

[
(Q/K,;s_{\rm U2U}),
]

[
(Q/K,;B_{\rm U2U}),
]

[
(Q/K,;\xi_g),
]

其中

[
g_{iq}\leftarrow\xi_g g_{iq},
\qquad
0<\xi_g\le1.
]

这样：

- (B_{\rm U2U}\downarrow) → communication-limited；
- (\xi_g\downarrow) → sensing/information-limited；
- (\rho_I^\star<1,\rho_C<1) 但 FRIDS 仍失败 → coordination-limited。

这会让“4-class feasibility phase diagram”真正完整。
