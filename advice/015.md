# 二、P4.2 要做，但我建议升级“anytime-valid”的实现

你现在提出：

[
7.5k\rightarrow15k\rightarrow30k\rightarrow60k
]

加 alpha-spending。

方向正确，但有一个统计术语需要收紧。

如果你是在这四个**预先固定的 look** 上运行 Clopper–Pearson，并给四次 look 分配 (\alpha)，严格说它是：

> **group-sequential repeated confidence procedure**

而不是真正意义上的“任意停止时刻都合法”的 confidence sequence。

如果论文要正式写：

> **anytime-valid QoS certification**

我建议直接上真正的 Bernoulli **time-uniform confidence sequence / e-process**。这是成熟统计工具，不需要自己发明。Waudby-Smith 与 Ramdas 的 JRSS-B 工作直接针对 bounded means 构造 betting CS，并利用非负超鞅与 Ville 不等式获得 time-uniform validity。([OUP Academic](https://academic.oup.com/jrsssb/article/86/1/1/7043257?utm_source=chatgpt.com))

### 推荐的最干净实现

对于每一个 target/error stream：

[
X_t\in{0,1},\qquad
S_n=\sum_{t=1}^{n}X_t.
]

取 Beta mixture，例如

[
a=b=\frac12.
]

对候选错误率 (p) 定义

[
M_n(p)=
\frac{
B(S_n+a,n-S_n+b)
}{
B(a,b),
p^{S_n}(1-p)^{n-S_n}
}.
]

在真实 (p) 下，(M_n(p)) 是非负 martingale，因此由 Ville 不等式，

# [ C_n

\left{
p:M_n(p)<\frac1\delta
\right}
]

满足

[
\Pr\left(
\forall n,\ p\in C_n
\right)\ge1-\delta.
]

这意味着你可以：

[
7.5k,\ 15k,\ 30k,\ 60k
]

甚至以后 45k、52k 查看都没有问题——**停止时间可以由数据决定**。这正是 anytime-valid 的价值。现代 betting CS 的理论就是为这种 bounded/Bernoulli sequential inference 建立的。([OUP Academic](https://academic.oup.com/jrsssb/article/86/1/1/7043257?utm_source=chatgpt.com))

# 四、P4.2 应该预注册什么

我建议一次性冻结下面这个 protocol，不允许中途调 threshold、scheduler、geometry 或 seed。

唯一建议的执行清单是：

1. **冻结对象**：`geom=2, regime=congested, rho=1.8`，代码 `ec5812d`，fixed policy-B thresholds，不允许重新 calibration。
2. **全新样本**：建立独立 `cert_seed` namespace，最大 60k episode，并按 prefix 读取 `0:7.5k → 0:15k → 0:30k → 0:60k`，绝不能四次重新随机跑。
3. **同时认证 32 个 Bernoulli streams**：(2) algorithms × (8) targets × (2) errors（FA/MD），用总 familywise (\delta=0.05)，例如每个 stream 分配 (\delta_s=0.05/32)。union bound 不要求不同算法独立，因此继续 CRN 没问题。
4. **判决冻结**：
   [
   \mathrm{PASS}(A)
   \iff
   \max_q U^{A}*{FA,q}\le0.05,
   \max_q U^{A}*{MD,q}\le0.05,
   ]
   [
   \mathrm{FAIL}(A)
   \iff
   \exists q:
   L^{A}*{FA,q}>0.05
   \ \vee
   L^{A}*{MD,q}>0.05.
   ]
   真正的强 Gate 是
   [
   \boxed{
   \mathrm{PASS(CA)}
   \land
   \mathrm{FAIL(v2)}
   }.
   ]
5. **每阶段序列化**：incremental + cumulative 的 `n_H0/n_H1/n_FA/n_MD`、每个 target 的 CS 上下界、首次 crossing stage、scenario/hash、threshold hash、代码 tree、seed interval、CRN tape fingerprint。
6. **提前停止合法**：一旦 `CA PASS && v2 FAIL` 可以停止；到 60k 仍 UNCERTAIN，就明确报告“统计分辨率不足”，禁止继续无计划增加 MC。

这里不要再同时优化 (\mu_c)、(\lambda_{\max})、quantizer 或 task price。**P4.2 是 certification experiment，不是 development experiment。**

# 九、当前 density admission 的理论表述也要收一点

现在 admission 按：

[
\frac{\text{score}}{\tau}
]

排序，再 greedy 填 airtime。

这是合理的工程启发式，但这个问题本质上是每接收机一个 0-1 knapsack：

[
\max_{\mathcal A_j}
\sum_{i\in\mathcal A_j}v_{ij},
\qquad
\sum_{i\in\mathcal A_j}\tau_{ij}\le T_j.
]

**density greedy 对 0-1 knapsack 并非 exact optimum。**

所以论文里不要写：

> optimal density admission

而应该写：

> density-prioritized hard-feasible admission.

如果你以后特别需要一个理论 guarantee，有一个几乎不增加复杂度的办法：

[
\max{
\text{density greedy solution},
\text{best feasible singleton}
}
]

对标准非负 0-1 knapsack 可以得到经典的常数近似保证。

不过根据当前

[
\Delta_{\rm admission}\approx-0.038
]

我甚至不建议现在为它投入太多篇幅。它更适合定位为：

[
\boxed{\text{feasibility fuse / secondary refinement}}
]

而不是论文主创新。

# 十、Freedman bridge 仍然没有在拥塞状态下真正闭合

这一点 P4.1b 没有修，也不该在 P4.1b 修。

真实拥塞情况下，owner 收到的增量实际上类似：

# [ Z_{iq,t}

I^{\rm adm}*{iq,t}
I^{\rm link}*{iq,t}
X_{iq,t}.
]

但当前 bridge 在计算 predictable drift 时，依然主要用 link reliability (s_{io(q)})，而没有把 admission event/probability 真正纳入 drift。

所以现在不能在 congested regime 写：

> exact predictable drift.

一个数学上非常干净的修法，是把 filtration 分成两层：

[
\mathcal F_{t^-}
\subset
\mathcal F_{t}^{\rm adm}
\subset
\mathcal F_t.
]

先揭示调度和 admission randomness，使

[
I^{\rm adm}_{iq,t}
]

对 (\mathcal F_t^{\rm adm}) 可测，然后：

# [ \mathbb E[ Z_{iq,t} \mid \mathcal F_t^{\rm adm} ]

I^{\rm adm}*{iq,t}
s*{io(q)}
\mu_{iq}.
]

于是

# [ M_t

\sum_{\tau\le t}
\left(
Z_\tau-
\mathbb E[Z_\tau|\mathcal F_\tau^{\rm adm}]
\right)
]

才是真正的 martingale。

这个修复可以放到 P4.2 以后做，因为它**不影响 P4.2 的经验 QoS certificate**，但影响最终 theorem。

# 十二、P4.2 以后最值得做的创新：Margin-Certified Sparse Dual Bus

这是我认为目前最值得升级成**论文第二核心创新**的地方。

既然 control bus 是剩余物理短板，就不要简单说“压缩控制包”。

[
\boxed{
\text{Margin-Triggered / Certificate-Aware Sparse Price Broadcasting}
}
]

设 UAV (i) 理想 best-response 的第一、第二名 margin：

# [ m_i

J_{i,(1)}-J_{i,(2)}.
]

价格量化、陈旧和省略引入最大 score error：

[
E_i
\le
g_i^{\max}\epsilon_\pi
+
c_i^{\max}\epsilon_\lambda
+
E_i^{\rm stale}.
]

那么只要：

[
\boxed{
m_i>2E_i
}
]

就有：

# [ \arg\max J_i

\arg\max \widehat J_i.
]

换句话说：

> **当控制信息误差不可能改变 sensing/report action 时，就不发送新的 price update。**

这就不再是普通的 event-triggered communication，而是：

[
\boxed{
\text{decision-preserving communication suppression}
}

通信节省有明确的 sensing-decision certificate。

这同时满足你要求的三个方向：

[
\text{数学：action-invariance bound}
]

[
\text{通信：减少 control airtime}

[
\text{感知：保证 sensing/report action 不改变}

而且和现有 Dual-Bus 主线天然连接，不需要生硬加 MAPPO、GNN 或新的复杂模块。
