# 001 号建议的执行记录：G11 Physical-to-Task Information Shaping

本文件记录 advice/001（聚拢+升华+精炼总纲）的落地：研究点固定为
reliable-information shaping，验证"物理→任务可行性定律"能否预测
最终检测时延。**结论：可行性定律是必要条件但非紧预测器；停止
OTFS grid 优化作为延迟杠杆；保留框架，下一审计回 communication。**

---

# 一、研究点固定（001 §1-2）

研究问题锁定为：
> 固定物理资源 + 受限 U2U 下，OTFS 能产生多少可可靠交付的任务检测
> 信息（`g_{iq}=s_{io_q}I^+_{iq}(G)`，唯一货币 nats/cycle），何时足以
> 支撑多目标检测，分布式 UAV 如何在线分配。

三层主干：OTFS 创造信息（物理信息塑形）→ 通信收缩算子 → FRIDS
供需平衡。以后所有优化只改变这条链上的一个映射，不再换研究点。

# 二、G11 结果（`results/information_shaping_gate.json`）

| 步骤 | 结果 |
| --- | --- |
| **G11-A** 物理账本闭合 | TB=N_ν·N_τ=4096 固定，能量结构相同 → 闭合 |

# 三、结论（按 001 §12 G11-C 规则）

1. **保留**：reliable-information 框架（研究问题固定）、FRIDS-v2
   （冻结在线层）、bottleneck-subset 可行性定律（必要条件；G10-C 已证
   网格**决定工作点可行性**）。
2. **停止**：OTFS grid 优化作为延迟改进杠杆（H_LB 不紧预测 + 盲验证无
   >5% 优势）。
3. **下一审计**：communication ~12.5% headroom（sensing 已审完：
   主瓶颈但非能量可分配、H_LB 不紧预测）。

# 四、诚实边界

- G11-B 的 Spearman 0.67 是 8 场景 × 3 网格、calib-margin=2.0 下的
  结果（margin=1.0 时可行格样本太少 0.82 不可靠）；
- H_LB 用静态信息下界 d_kl(1-β,α) 与最优分配 F_G(S)，而实现 J 由
  弱目标实际被服务的 UAV 数×g 决定——两者机制不同，故相关性中等；
- G11-C 因 task/SNR-optimal 与 balanced 重合而无法判别（网格间的
  H_LB/g 差异不足以在留出场景产生稳定延迟差）。

# 五、研究定位（001 §13 一句话）

> 本研究不是寻找更复杂的 UAV 调度算法，而是研究固定感知资源与受限
> U2U 下，OTFS 能产生多少可可靠交付的任务检测信息、何时足以支撑
> 多目标检测、以及分布式 UAV 如何在线把有限可靠信息分配给最需要的
> 目标。

后续"持续优化"按 001 §11 的四问纪律（数学有意义 / 物理真实 /
>5% oracle headroom / 改变最终任务量 max_q E1[T_q]）执行，研究问题
不再漂移。
