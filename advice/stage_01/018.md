# 四、这个公式能同时解释 redundancy 和 synergy

# 十三、文献上也支持把创新点放在这里，而不是“相关检测本身”

相关传感器的 sequential distributed detection 已经有明确先例。Zhang、Khanduri 和 Varshney 使用 copula 描述空间相关观测，并研究了 noisy communication 下的 distributed sequential detection，因此不能声称“首次考虑相关传感器序贯检测”。([IEEE Xplore](https://ieeexplore.ieee.org/iel7/9034466/9048648/09048804.pdf?utm_source=chatgpt.com))

在线 sensor selection 用于 time-optimal sequential detection 也不是新问题，早期工作已经研究过 sensor selection 与 sequential hypothesis testing 的结合。([arXiv](https://arxiv.org/abs/0909.1801?utm_source=chatgpt.com))

与此同时，近期 multi-UAV ISAC 工作更多集中在 UAV-BS association、trajectory、bandwidth/PCRB 等联合优化，而不是你现在这条“strictly-local sequential detection deficit + conditional joint information”路线。([arXiv](https://arxiv.org/abs/2603.11502?utm_source=chatgpt.com))

所以创新定位应该非常克制地写成：

[
\boxed{
\text{不是首次研究相关检测，也不是首次做 sensor selection；}
}

而是：

> **在严格分布式、通信受限的多 UAV ISAC 序贯检测中，用剩余检测缺陷对条件联合检测信息进行定价，使感知相关性通过局部 innovation KL 直接进入任务调度。**

这个定位比较稳。
