是的。前两轮我把“收敛”理解得过于偏向**缩小问题规模**，结果虽然更稳，但确实把研究的上限也一起压低了。

我重新查了截至 **2026 年 8 月 16 日** 的最新工作后，判断发生了变化：现在更合适的不是退回“静态报告选择 + (P_D) 融合”，而是把现有系统整体提升成一个**任务驱动、闭环、主动获取信息的多 UAV ISAC 检测系统**。关键是“开放但不发散”——所有新增自由度都由同一个数学量统一，而不是再增加 RIS、MAPPO、轨迹等独立模块。

# 1. 最新文献实际上已经在发生范式变化

最近几篇工作给出的信号非常一致。

2026 年 3 月的 **Semantic Sensing** 已经明确提出：不要先追求信道重构，再做下游任务，而应让物理层直接提取与最终任务相关的信息；其核心是 information bottleneck，并直接优化 pilot/resource 与任务性能，而且作者明确指出框架可以扩展到 OTFS。([arXiv](https://arxiv.org/html/2603.29102v1))

2026 年 4 月的 **Goal-oriented Resource Allocation for Collaborative ISAC** 已经研究“分布式设备感知 + 特征上传 + 融合中心推断”，用 discriminant gain 代替普通 SNR/MSE 作为资源调度依据，而且发现设备相关性越强、通信越受限，联合 task-oriented scheduling 的优势越明显。([arXiv](https://arxiv.org/abs/2604.16556))

2025 年的 **Inference-Optimal ISAC** 更直接：不是最小化 MSE，而是围绕最终 inference error 进行资源分配，结果得到 task-oriented water-filling，并倾向于把功率分给真正有判别价值的 feature。([arXiv](https://arxiv.org/abs/2510.20429))

更值得注意的是 **2026 年 8 月 4 日**刚提交的 distributed OFDM-ISAC 工作：它已经不再传完整 sensing tensor，而是传**task-oriented candidate latent tokens**，在有限反馈预算下进行 coarse-to-fine sensing；也就是说，“传什么信息”本身已经成为 sensing system 的优化变量。([arXiv](https://arxiv.org/abs/2608.03319?utm_source=chatgpt.com))

另外，2026 年 7 月最新的 network-level ISAC 工作进一步证明：**相同的时频资源，由于几何位置不同，其感知价值并不相同**，并从 CRLB 梯度推导 geometry-aware resource allocation。([arXiv](https://arxiv.org/abs/2607.29060))

而 2026 年 active sensing 工作则重新把 Chernoff 的主动假设检验引入无线感知：不是被动接收固定观测，而是根据过去观测动态选择**下一次最有信息价值的 sensing action**。([arXiv](https://arxiv.org/pdf/2607.00056))

所以最新趋势实际上已经从

[
\text{resource allocation}
]

逐渐转向

[
\boxed{
\text{task-oriented}
+
\text{active sensing}
+
\text{information acquisition}
+
\text{closed-loop decision}
}
]

你的系统应该顺着这一方向升级，但不能简单照搬 DG、semantic latent 或神经网络。

# 2. 我建议真正“拔高”的核心：Detection Information Flow

你当前模型的主要限制是：

[
\text{产生证据}
\rightarrow
\text{报告选择}
\rightarrow
\text{融合}.

于是把系统重新定义为：

[
\boxed{
\textbf{Task-Oriented Active Distributed Detection}
}
]

或者暂时称为：

[
\boxed{
\text{Post-Communication Active Detection Information}
}
]

核心不是单纯 (P_D)，而是整个系统中的 **Detection Information Flow**。

# 3. 用一个数学量把 OTFS、通信、几何、功率、移动全部统一

对目标 (q)：

[
H_q\in{0,1}.
]

第 (t) 个 sensing cycle，UAV (i) 选择动作

# [ a_{i,t}

{
\Omega_{i,t},
P^{s}*{i,t},
b*{i,t},
r_{i,t},
u_{i,t}
},
]

其中：

- (\Omega_{i,t})：OTFS DD probing/resource pattern；
- (P^s_{i,t})：感知功率；
- (b_{i,t})：报告精度；
- (r_{i,t})：报告/协作对象；
- (u_{i,t})：必要时才包含小尺度位置调整。

注意，不是说这些变量必须全部同时优化。

而是它们全部通过一个统一接口：

[
a_{i,t}
\longrightarrow
p_{0,iq}(y|a_{i,t}),
\quad
p_{1,iq}(y|a_{i,t}).
]

其中 (y) 已经是**经过 sensing + quantization + BSC + erasure 之后真正送到决策端的信息**。

然后定义两个方向的检测信息：

# [ \boxed{ I^{+}_{iq}(a)

D_{\rm KL}
\left(
p_{1,iq}\Vert p_{0,iq}
\right)
}
]

和

# [ \boxed{ I^{-}_{iq}(a)

D_{\rm KL}
\left(
p_{0,iq}\Vert p_{1,iq}
\right).
}
]

这两个量有非常清楚的检测意义。

对 LLR

# [ L_q(t)

\sum_{\tau=1}^{t}
\log
\frac{p_1(y_\tau|a_\tau)}
{p_0(y_\tau|a_\tau)},
]

有

# [ \mathbb E_{H_1} [ \Delta L_q ]

D_{\rm KL}(p_1\Vert p_0),
]

而

# [ \mathbb E_{H_0} [ \Delta L_q ]

- 

D_{\rm KL}(p_0\Vert p_1).
]

也就是说：

[
\boxed{\text{KL divergence = 平均决策证据增长速度}}
]

这就比单纯 SNR、deflection、甚至瞬时 (\Delta P_D) 更适合做**主动控制量**。

# 6. 优化目标也应该从“固定预算最大化 (P_D)”升级

目前主要问题：

[
\max
\min_q E[P_{D,q}]
\quad
\text{s.t. } B.
]

当然合理。

但对于主动检测，更有理论意义的是：

[
\boxed{
\min_{\pi}
\max_q
\mathbb E_\pi[T_q]
}
]

subject to

[
P_{FA,q}\le\alpha_q,
]

[
P_{MD,q}\le\beta_q,
]

[
E_{\rm total}\le E_{\max},
]

[
B_{\rm report}\le B_{\max}.
]

即：

> **在规定 detection reliability 下，尽可能快地完成最难目标的检测。**

这个问题明显比：

> 给我 20 bit，谁的 (P_D) 高一点？

层次高。

而且它天然有现实意义：

- 简单目标达到可靠判决后停止浪费资源；
- 强 UAV 不必不断重复提交冗余证据；
- 资源自动转给 weak target；
- 通信很差的 UAV 可以主动换 another sensor；
- 几何不好时可以改变 probing/位置。

# 7. 这才是真正合理的“动态 max-min”

把目标 (q) 当前的未完成程度定义成 detection deficit，例如

# [ d_q(t)

\text{distance of current belief/LLR to decision boundary}.
]

那么目标不是静态：

[
\min_q P_D(q)
]

而是动态降低最大的

[
\boxed{
\text{remaining decision time}
}
]

可以构造：

[
\tau_q^{\rm pred}
\approx
\frac{d_q(t)}
{\max_a I_q(a)}.
]

每个 cycle 优先处理

# [ q^\star

\arg\max_q
\tau_q^{\rm pred}.
]

然后再决定哪架 UAV 最合适：

# [ (i^\star,a^\star)

\arg\max_{i,a}
\frac{
I_{iq}^{\rm post}(a)
}{
C_{iq}(a)
}.
]

这与普通 marginal gain 非常不一样。

它不是：

[
\frac{\Delta P_D}{\mathrm{bit}},
]

而是：

[
\boxed{
\frac{
\text{expected decision-information acquisition}
}{
\text{physical cost}
}.
}
]

这可以成为新的核心算法结构。

OTFS 不再只是标签。

用 local detection-information gain + global dual prices，实现分布式协同，并以 centralized active oracle 为小规模上界。

这四个贡献的理论一致性远强于现在 G1–G90 的堆叠结构。

在现有系统直接计算

**如果 KL/Chernoff 完全没有优势，这条新主线直接停止。**

## 最终判断

这次我不建议再退回“只做 report selection”。

**真正值得冲的方向是把现在的 selective soft-information fusion，从一个“通信受限后的资源分配问题”，提升成一个“通信受限下的主动信息获取与闭环检测问题”。**

简化成一句话就是：

[
\boxed{
\textbf{从“选择已有信息”升级为“主动创造最有价值的信息”。}
}
]

而最新 task-oriented ISAC、Semantic Sensing、geometry-aware network ISAC、active sensing 和 task-oriented distributed feedback 的发展，恰好都在向这个方向靠近。([arXiv](https://arxiv.org/html/2603.29102v1))

这条路比简单继续强化 NOMP、增加一个 RIS、增加一个 MAPPO 模块风险更高，但理论天花板也明显更高；同时它又能吸收你现在已经建立的 (P_D)-optimal fusion、BSC/erasure、Exact oracle、NOMP 和分布式机制，而不需要把已有工作全部推倒。

如果继续推进，我现在会优先做 **Gate A → Gate B**，甚至暂时不动轨迹和隐蔽性：先证明“post-communication detection information + active sensing”确实能够击败当前 Static NOMP。**只要这两个 Gate 成立，整个项目的理论定位就可以真正上一个台阶。**
