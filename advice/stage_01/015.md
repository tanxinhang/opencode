# 一、审计做了什么

## 1.1 模型（`uav_otfs_isac/evidence_correlation.py`）

高斯公共因子证据模型（与 G3-G5 层 moment-matched 的相关结构一致，
H0/H1 同协方差）：

`Y_i = δ_i·H1 + √ρ_s·C + √(1−ρ_s)·N_i`，C、N_i i.i.d. 标准正态，

`δ_i = √(2·g_iq)` 由 FRIDS 实际聚合的可靠信息反解。联合 KL 有
Sherman-Morrison 闭式（Theorem 4.104）：

`G_q(S) = (Σδ² − ρ_s·(Σδ)²/(1+(|S|−1)ρ_s)) / (2(1−ρ_s))`，

`R_q(S) = 1 − G_q(S)/Σ_{i∈S} g_iq = (ρ_s/(1−ρ_s))·(a/(1+(|S|−1)ρ_s) − 1)`，

`a = (Σδ)²/Σδ²` 为对齐度（单体=1，全等=|S|）。闭式经 Monte-Carlo
采样逐点验证（测试 `test_closed_form_matches_sampling`）。

## 1.2 Gate（`scripts/run_evidence_dependence_gate.py`）

K=16/Q=8，ρ_s∈{0,0.2,0.5,0.8}，逐目标报告 R_q(full)/R_q(topk)/对齐度/
条件边际 `ΔG_{i|S,q}`（G8-B 的量）+ 高斯序贯检测的延迟后果。

# 三、三个理论要点（FORMAL_PROOFS §5D）

1. **闭式 + 验证**：`R_q(S)` 的闭式与 Monte-Carlo 一致；ρ=0 或
   |S|=1 时 R=0（无冗余），物理区 ρ∈{0.2,0.5} 单调增。
2. **KL chain rule 条件边际**（G8-B 的量）：`ΔG_{i|S,q} = G(S∪{i})−G(S)
   ≥ 0`；ρ=0 时等于 singleton，但**不被 singleton 上界**——G 非次模，
   013 的"不要默认次模"警示被数值验证（高 ρ 时条件边际可超 singleton，
   因条件化降低方差使 UAV 更可判别）。
3. **延迟后果**：全联合每周期顺序漂移是 `G_q(S)`，singleton 乐观延迟
   低估 `1/(1−R)` 倍；序贯测试确认。

**非主张**：同协方差模型在极端 ρ=0.8 对异质联合因噪声白化回弯
（正交私有分量被 1/(1−ρ) 放大），故生命门取物理区 ρ∈{0.2,0.5}；
R≈80% 特定于本同质目标内剖面。

# 四、下一步：G8-B Conditional-Reliable-Information FRIDS

013 §7 的方案：把 FRIDS 的调度值从 singleton `g_iq` 替换为

`J_{iq}^{corr} = y_q · ΔG_{i|Ŝ_q,q} / (D_q + ε)`，

其中 `Ŝ_q^{(i)}` 只能由 UAV i 实际收到的 intent/token 推断（不能调用
全局 coalition），仍严格满足 `a_{i,t}=π_i(I_{i,t})`。创新定位：
"不用 RL 学 diversity，而是用 conditional KL 定义 diversity 的任务价值"。

建议先做一个小 Gate 验证 `ΔG_{i|S,q}` 的实际数值对调度的影响：
只替换调度值、其余冻结，对比 singleton-FRIDS-v2 与 conditional-FRIDS，
主指标仍 `J=max_q E1[T_q]`，同时报告每 UAV 报告价值分布的变化。
若 `ΔG` 校正后弱目标（其联合被高估最严重）的延迟或误差改善，则
采纳；否则如实报告 conditional 校正在该场景族不显著。
