# 一、做了什么

## 1.1 诊断（`frids.simulate_frids_v2` 增加 audit 能力，默认路径逐字节不变）

- `price_mode="local"`（冻结）vs `price_mode="common"`（离线 oracle：
  动作索引用 `y = mean_i y^(i)`，其余全部保持局部）——直接隔离
  "价格分歧"的延迟代价；
- `audit=True` 每周期追踪：
  - `D_y`：UAV 两两局部价格 L1 分歧；
  - `D_v`：两两局部归一化价值分歧；
  - `deficit_gap`：owner 缺陷（停止判决状态）与各 UAV 局部缺陷之差；
  - 动作不变性证书 `P(m_i > 2 E_i)`（Theorem 4.109，充分条件）；
  - **实现的动作改变率**并分解为"价格贡献"（局部价 vs 公共价）与
    "缺陷贡献"（局部缺陷 vs owner 缺陷）。

## 1.2 理论（Theorem 4.109）

理想 score `J=y_q·v_iq`、局部 `Ĵ=ŷ·v̂`；若 `|ŷ−y|≤ε_y`、`|v̂−v|≤ε_v`、
`v≤V_max`，则 `|Ĵ−J| ≤ V_max·ε_y + ε_v + ε_y·ε_v = E_i`；若动作 margin
`m_i > 2E_i` 则局部 argmax 不变。token 年龄界 `|D^o−D̂|≤a·L^max+ε_L`
进入 ε_v，构成 token age → belief uncertainty → score uncertainty →
action stability 链。定理经 200 组随机扰动数值验证（测试）。

# 二、G9A 结果（`results/local_dual_audit.json`，K=16/Q=8，3 场景）

| 量 | 值 |
| --- | --- |
| common-price 延迟 gap | **−1.8%**（<2%） |
| D_y（价格分歧） | 0.23 |
| owner-局部 deficit gap | 2.11 |
| P(m_i > 2E_i) | ≈0（保守充分条件） |

**裁决：FRIDS-v2 在延迟目标上足够——局部对偶分歧不是延迟瓶颈，冻结算法。**

# 三、诚实边界

- **动作不变性证书（充分条件）实测不成立**：局部动作 ~67% 偏离
  公共价/owner 锚定理想（价格与缺陷各贡献一半），P(m>2E)≈0。
  因此论文**不得**声称"分布式决策与集中式决策动作级一致"；
  只能声称"最坏目标延迟对局部对偶分歧鲁棒"（总量信息驱动）。
- 证书上界保守（`V_max·ε_y` 在缺陷趋零时放大），P≈0 高估不稳定性。
- common-price oracle 是离线参考，不是可部署共识方案（R_coord≤2
  约束不允许 consensus）。
