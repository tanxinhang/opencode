# 二、G7 稳健性审计（`results/deep_audit_g7.json`）

**审计 1（固定 λ_base 出样本）**：原 Gate 用场景 0 选出的 λ_base
（deficit 0.4 / info 0.1）在场景 1、2 上：
- 非拥塞 deficit：ΔJ +3.9% / −1.4% / +2.4%（均值 +1.6%，超 2% 门），
  削减 33.8% / 17.3% / 29.8%（场景 1 仅 17%）→ **不成立**。
- 临界 deficit：ΔJ **+11.8% / +14.0% / +16.6%**（均值 +14.1%！
  全场景显著退化）→ **不成立**。
- 拥塞 info：ΔJ −4.1% / +4.3% / +16.0%（场景 2 退化 16%）→ 不成立。

**审计 2（每场景重选 λ_base，按 Gate 自身选择规则）**：
- 非拥塞生命门（存在 λ 使 ΔJ≤2% 且削减≥30%）通过 **1/3** 场景。
- 拥塞门（J 改善≥5%）通过 **0/3** 场景。

**结论：G7 的定量主张（52.8% 削减 @ ΔJ≤0.4%、临界 53% 削减）
是场景 0 的样本内结果，出样本不成立。** 机制（airtime 约束报告、
report/no-report）本身可行，但"通信效率层"的量化收益场景相关，
且拥塞区从未达到 5% 门。论文不应把这些数字作为主张。

# 三、G8A 模型敏感性审计（`results/deep_audit_g8.json` probe4）

- 同质剖面（本场景族，对齐 ~15/16）：ρ=0.5 时 R=**80.1%**。
- **集中剖面**（1 个主导 UAV + 15 个弱 UAV，对齐 →1）：ρ=0.5 时
  **R=−7.1%（联合 KL 反而超过 singleton 加总！）**。

**结论：R_q(S) 高度依赖 coalition 对齐度。** 同协方差高斯模型在
`a < 1+(|S|−1)ρ` 时出现负冗余（噪声白化放大主导 UAV 的私有分量，
匹配滤波效应）。"singleton 高估联合信息 80%" 只在同质剖面成立；
对实际更常见的集中剖面（FRIDS 本就倾向于每目标集中少数强 UAV），
singleton 加总既不显著高估也不显著低估。**G8A 的 80% 主张不可
外推；条件调度的价值不能建立在"冗余高估"这一模型敏感结论上。**

# 四、G8B 统计与机制审计（`results/deep_audit_g8.json`）

**统计（5 场景配对 bootstrap 95% CI，正值=改善）**：
| 对比 | 均值 | CI | 逐场景符号 |
| --- | --- | --- | --- |
| Step1 ρ_s=0.5 vs FRIDS-v2（独立世界） | +1.9% | [−1.9%, +5.7%] | 2/5 正，**不一致** |
| Step2 一致调度 vs v2（相关世界） | +2.8% | [−1.5%, +7.1%] | 2/5 正，**不一致** |
| **Step2 一致 vs 同世界 singleton** | **+6.0%** | **[+1.1%, +10.8%]** | **4/5 正，一致** |

- **唯一统计支持的结论**：在相关世界下，条件调度相对同世界
  singleton 改善最坏目标延迟 **+6.0%**（CI 排除 0，4/5 场景）。
- **Step1 的独立世界改善（原 3 场景 −4.2%）不复现**：5 场景下均值
  +1.9%、CI 含 0、3/5 场景反而退化。原结论是少数场景的样本内假象。

**机制审计**：
- **coalition 时效性**：perfect 上一周期真集合 vs 本地 intent 图，
  均值差 **−0.71%**（完美 oracle 仅好 ~0.7%）→ 严格局部实现的
  滞后/投递代价很小，不是问题。
- **ρ_s 单调性**：Step1 的 ΔJ 曲线非单调（如场景 4：
  +0.8%/+3.5%/+8.2%/−2.0% 随 ρ_s=0.1/0.2/0.3/0.5），有峰值且噪声大
  → 收益对 ρ_s 敏感、有过拟合风险，不能当作单调参数效应。
