需要优化，但现在**不应该再换一个更复杂的调度器**。从最新结果看，FRIDS 已经完成了从“补丁式 dual-G”到“有统一任务含义的算法”的关键跃迁：在 5 个场景上，(12/6) 从 5.16 降到 2.75，(16/8) 从 5.36 降到 3.26，且 (16/8) 5/5 场景获胜、错误约束满足；因此下一阶段应该进入 **FRIDS 的数学闭环与结构优化**，而不是再造 FRIDS-Plus、再加 AoI、再加 NOMP/MAPPO。

不过我认为当前 FRIDS 里还有几个相当值得先处理的基础问题，其中有两个甚至比继续追求 (J) 下降更重要。

## 一、先做算法正确性审计，而不是性能优化

当前最需要检查的有四点：

1. **(g_{iq}) 的投递可靠性可能存在重复计数。** 当前模型把
   [
   g_{iq}=\max_a I_{iqa}^{+,post},s_{i,o_q}
   ]
   作为可靠信息增益；但系统前面的定义又明确说 `post-communication kernel` 已包含“量化 + BSC + detectable erasure”。如果这里的 (I^{+,post}) 已经包含擦除，则你之前建立的擦除恒等式实际上已经给出
   [
   I^{+,post}=s,I^{+,rec},
   ]
   此时再乘一次 (s) 会变成
   [
   s^2I^{+,rec},
   ]
   对差链路进行了**二次惩罚**。正确形式必须二选一：
   [
   g_{iq}=I_{iqa}^{+,post},
   ]
   或
   [
   g_{iq}=s_{i,o_q}I_{iqa}^{+,rec}.
   ]
   两者不能同时出现。这一点建议做成单元测试：`FRIDS gain == KL(final observable kernel)`。当前文档的两个定义确实存在需要澄清的空间。
2. **FRIDS 当前的原始问题和 (\nu) 的 simplex 投影并没有完全数学对齐。** 文档给出的松弛是
   [
   \max z,\qquad
   \sum_i x_{iq}g_{iq}\ge zD_q.
   ]
   对这个问题做 Lagrange 对偶，(z) 项为
   [
   z\left(1-\sum_q\nu_qD_q\right),
   ]
   因而对偶可行条件应为
   [
   \boxed{\sum_q\nu_qD_q=1},
   ]
   并不是普通的
   [
   \sum_q\nu_q=1.
   ]
   但现在文档写的是把 (\nu) 投影到普通 simplex，同时本地 score 用
   [
   \nu_qg_{iq}.
   ]
   除非实现中已经对 (D_q) 做了某种等价重参数化，否则这两者理论上并不完全一致。
3. **当前价格更新还存在潜在的量纲问题。** 现在写的是
   [
   \nu\leftarrow
   \Pi_\Delta[
   \nu+\mu(\bar D-\bar S)
   ].
   ]
   但 (D_q) 是“剩余 LLR/information deficit”，而 (S_q) 更接近“每周期收到的信息量”。如果一个是存量、一个是流量，直接相减仍然有类似 F0-A 当初“单位不匹配”的风险。更严格的比较应该是
   [
   r_q^{req}(t)=\frac{D_q(t)}{H_{\rm rem}},
   ]
   和
   [
   S_q(t),
   ]
   两者都是 information/cycle；或者直接比较无量纲的
   [
   \frac{S_q(t)}{D_q(t)}.
   ]
4. **必须做 FRIDS 的信息来源 provenance audit。** 当前 P-DIST 的核心要求是
   [
   a_{i,t}=\pi_i(I_{i,t}),
   ]
   禁止在线使用全局量。
   因此要逐项确认 UAV (i) 算
   [
   \nu_q,\quad D_q,\quad \bar S_q,\quad g_{iq}
   ]
   时用到的信息究竟来自哪里。尤其是“owner 实际收到多少信息”并不是任意 helper UAV 天然知道的。如果当前代码直接读取 simulator 中的 owner belief 或真实 delivery outcome，那 FRIDS 虽然性能很好，却重新引入了隐式中心信息。这个问题要先审计清楚。

这四项里面，我会把 **2 和 4** 视为最优先，因为它们直接关系到 FRIDS 能不能严格叫“由原始-对偶理论导出的分布式算法”。

# 二、还有一个非常基础的通信记账问题必须修

当前 token 被写成：

[
{q:2,\hat L:5,u:2,r:2,\chi:2,intent:2,stamp:4},
]

总共 19 bit。

但是当前已经测试：

[
Q=6,\quad Q=8.
]

2 bit 只能编码：

[
2^2=4
]

个目标。

所以如果 `q:2 bits` 真的是目标 ID，那么到了 (Q=8) 至少必须：

[
b_q=\lceil\log_2Q\rceil=3.
]

这不是算法性能问题，而是基本通信记账问题。

好消息是你已经发现：

[
u/r/\chi/stamp
]

此前属于大量未使用 payload，所以完全不需要增加总 token 长度。可以定义：

[
b_q(Q)=\lceil\log_2Q\rceil
]

并从 dead payload 中动态腾出 1–2 bit，仍然保持：

[
B_{\rm token}=19.
]

如果目标 ID 实际由时隙/共享 codebook 隐式确定，那也必须明确写进系统模型；不能同时写“2-bit q”和“Q=8”。

这个修正看起来小，但对“通信原则成立”非常重要。

# 三、真正值得做的算法升级：FRIDS-v2 不换思想，只把对偶理论做严格

我建议不要再造新算法名称，而是把 FRIDS 升成一个**Dual-Consistent FRIDS**。

把原问题写成

[
\max_{x,z} z
]

subject to

[
\frac{\sum_i x_{iq}g_{iq}}
{D_q}
\ge z,
\qquad\forall q,
]

[
\sum_qx_{iq}\le1,\qquad
x_{iq}\ge0.
]

这里：

[
\frac{\sum_i x_{iq}g_{iq}}{D_q}
]

有非常明确的意义：

> 本周期可靠信息供给占剩余检测任务的比例。

这样问题的对偶权重可以直接放在普通 simplex：

[
y_q\ge0,
\qquad
\sum_qy_q=1.
]

每架 UAV 的局部 score 自然成为：

# [ \boxed{ \mathcal J_{iq}

y_q
\frac{g_{iq}}{D_q}
}
]

而不是人为拼接 congestion penalty。

这里有一个很重要的区别：

过去：

[
\eta(K)
]

在问“这个目标是不是太拥挤”。

现在：

[
\frac{S_q}{D_q}
]

在问“这个目标得到的可靠信息是否已经超过其实际任务需求”。

因此它惩罚的是：

[
\boxed{\text{任务过服务}}
]

而不是：

[
\boxed{\text{UAV 数量多}}
]

这比 F0-F 的 (n^{-2}) 解释更加完整。

# 四、我建议价格更新也从 projected subgradient 改成 mirror descent

现在硬设置：

[
\nu_{\min}
]

来防 starvation，多少还是一个人为机制。

更漂亮的办法是使用 exponentiated-gradient：

# [ y_q(t+1)

\frac{
y_q(t)
\exp[\mu e_q(t)]
}{
\sum_k
y_k(t)
\exp[\mu e_k(t)]
},
]

其中：

# [ e_q(t)

## \bar r(t)

\frac{S_q(t)}
{D_q(t)+\epsilon}.
]

服务不足：

[
S_q/D_q\downarrow
\Rightarrow
y_q\uparrow.
]

已经获得足够服务：

[
S_q/D_q\uparrow
\Rightarrow
y_q\downarrow.
]

它有三个好处：

- 天然保持 (y_q>0)，不需要 `nu_floor`；
- 天然满足 simplex；
- 对有界 (e_q)，可以直接借用标准 mirror-descent 分析，得到静态松弛上的 (O(\sqrt{T\log Q})) regret 量级。

需要强调：这个 regret 只能对**冻结 deficit / stationary gain 下的瞬时松弛**证明，不能宣称整个 sequential detection 全局最优。

但这已经足够形成一个可信的理论结果。

# 五、当前 feasibility certificate 还可以明显加强，而且这比再加 heuristic 更有创新性

现在的判断是单目标：

[
H_{\rm rem}C_q^{\max}
<
D_q^{info}
\Rightarrow
q\text{ infeasible}.
]

这是正确的必要条件，但它没有考虑：

> 多个目标抢同一批 UAV。

可以进一步定义任意目标子集：

[
\mathcal S\subseteq\mathcal Q,
]

并构造一个“信息负载 cut”：

# [ \boxed{ \rho(\mathcal S)

\frac{
\sum_{q\in\mathcal S}D_q^{info}
}{
H_{\rm rem}
\sum_i
\max_{q\in\mathcal S} g_{iq}
}
}
]

如果：

[
\rho(\mathcal S)>1,
]

那么即使 UAV 在未来所有周期都把资源最优分给这个目标子集，该子集所需的总信息也超过能够提供的上界，因此：

[
\boxed{\mathcal S\text{ 必然不可全部按时完成}}
]

这是一个非常有价值的 **distributed detection load cut**。

它正好把你后面想做的：

[
Q/K\times reliability
]

可行区域从“画实验图”提升成：

[
\text{理论必要条件}
+
\text{实验可行区域}.
]

我认为这比继续改 FRIDS index 更有论文价值。

# 六、FRIDS 中的 (I^+) 暂时不要换成 Chernoff

这里反而建议保持克制。

以前 Gate C 证明过跨量化设计时：

[
\text{Exact }P_D

> 

\text{Chernoff}

> 

I^+.
]

但 FRIDS 现在优化的是：

[
E_1[T_q],
]

而不是固定 (n) 的 (P_D)。

从 Wald 序贯检测理论看：

[
E_1[T]
\sim
\frac{\text{required evidence}}
{I^+}.
]

所以：

[
I^+

作为 FRIDS 的“每观测 H1 信息增长率”反而是具有直接理论意义的。

因此现在不要因为 Chernoff 曾经表现更好，就把：

[

]

换掉。

最多做一个后续 ablation：

[
I^+
\quad\text{vs}\quad
C_{\rm Chernoff},
]

但不应作为当前主优化。

# 七、如果 action 的功率/比特成本异构，还要检查一个问题

目前：

[
g_{iq}=\max_a I_{iqa}^+.
]

如果所有动作：

- 都占一个 detection cycle；
- 都已经满足单周期能量/bit硬约束；
- 成本近似相同；

这个写法没有问题。

但如果动作 (a) 之间存在明显不同：

[
E_a,\quad B_a,\quad T_a,
]

那么只取：

[
\max I^+
]

就不再符合 P-DIST 的资源原则。

这时候才应该扩展为：

# [ g_{iq}^{eff}

## \max_{a\in\mathcal A_i^{feas}} \left[ I_{iqa}^{final}

## \lambda_i^E E_a

## \lambda_i^B B_a

\lambda_i^C C_a
\right].
]

注意我建议**有异构成本再做**。

如果当前 action 成本基本固定，不要人为增加三个对偶变量。

# 八、P_FA≈0 暂时不要继续“优化到 0.05”

最新 F0-G1 已经说明：

- 但 (P_{\rm FA}) 依然接近 0；
- 真正绑定的是 (P_{\rm MD})。

这时候不要为了“充分利用约束”强行让：

[
P_{\rm FA}\rightarrow\alpha.
]

KKT 中约束本来就允许 slack。

如果系统优化的是：

[
\min E_1[T]
]

subject to

[
P_{\rm FA}\le\alpha,\qquad
P_{\rm MD}\le\beta,
]

那么最优点完全可能是：

[
P_{\rm FA}\ll\alpha,
\qquad
P_{\rm MD}=\beta.
]

只要继续放松 (A/B) 无法降低 H1 delay 而不违反 (P_{\rm MD})，就没有数学理由追求 (P_{\rm FA}=0.05)。

所以这个方向现在可以基本关闭。
