对，这次问题已经不是“理论还缺几个 lemma”，而是**理论核心选错了层级**。

你现在这三层虽然都能证明一些东西，但本质上还是：

[
\text{预测一个剩余时间}
\rightarrow
\text{做一次静态资源分配}
\rightarrow
\text{给单链路选一个量化器}.
]

它没有形成真正的**动态决策理论**。所以会出现一种很明显的感觉：定理越来越多，但算法还是“排序—扫描—注水—交换”，没有产生一个别人很难替代的核心求解器。

而且当前文档自己实际上已经把这个问题暴露出来了：`floor-cover` 虽然对静态 max-min (P_D) 是精确的，但“分配层与时间层未闭环”；`tau_pred` 仍是启发式；(I^+) 注水甚至已经被实验明确否定。 另一方面，Theorem 4.91 的精确性来自目标可分以后做 minimum-cost floor coverage，这个结果是正确且有用的，但从算法研究角度说，它确实更像“一个漂亮的静态子问题解”，还不是整个主动检测问题的核心。

我现在更建议：**把你表里的顶层、中层、底层全部推翻为同一个 Bellman 问题。**

------

# 一、真正应该研究的问题：不是检测时间预测，而是“最优停止 + 最优实验设计”

对目标 (q)，不要再把状态写成 (n,I^+,\tau_{\rm pred})。

真正的充分状态应该是 posterior：

# [ \pi_{q,t}

\Pr(H_q=1\mid\mathcal F_t),
]

或者等价的 posterior log-odds

# [ L_{q,t}

\log\frac{\pi_{q,t}}{1-\pi_{q,t}}.
]

一旦选择动作

# [ a_t

(i,;b,;P,;Q,;\Omega,\ldots),
]

你现在已经有完整的 post-communication observation kernel：

# [ p_h^a(y)

\Pr(Y=y\mid H=h,a),
]

因此状态更新其实是**精确的**：

# [ \boxed{ L_{t+1}

L_t+
\log\frac{p_1^{a_t}(Y_t)}
{p_0^{a_t}(Y_t)}
}
]

这才应该成为整个理论的第一条状态方程。

也就是说，量化、BSC、擦除、UAV选择、功率选择，都不再分别优化，而只是改变：

[
p_0^a(y),\qquad p_1^a(y).
]

------

# 二、顶层应该直接变成 Bellman 最优停止，而不是 `tau_pred`

对单个目标，定义：

[
V(\pi,B)
]

表示当前 posterior 为 (\pi)、剩余资源为 (B) 时，从现在开始的最小期望总代价。

例如 Bayesian 形式可以写成：

# [ \boxed{ V(\pi,B)

\min
\left{
C_{10}\pi,;
C_{01}(1-\pi),;
\min_{a:c(a)\le B}
\left[
c_t+\lambda c(a)
+
\mathbb E
V(\pi',B-c(a))
\right]
\right}.
}
\tag{1}
]

三个分支分别表示：

[
\text{判 }H_0,\qquad
\text{判 }H_1,\qquad
\text{继续观测}.
]

这一步非常关键。

因为现在：

> “什么时候停止？”

> “下一步选哪个 UAV？”

> “传几 bit？”

> “用哪个量化器？”

全部由**同一个 Bellman equation**决定。

而不是先用 Chernoff 设计，再用 floor-cover 分配，再用 (\tau_{\rm pred}) 选择目标。

经典 active sequential hypothesis testing 本来就是动态规划问题，而且已有工作研究了信息获取率下界和渐近最优策略；最近的 active sensing 工作也继续沿着“根据历史观测在线选择下一个 sensing configuration”的方向发展。([arXiv](https://arxiv.org/abs/1203.4626))

------

# 三、这样一来，你当前的 `tau_pred` 可以被“理论降维”

这是很重要的处理。

不要删除 `tau_pred`。

而是证明它只是 Bellman 最优策略在某个极限下的**一阶近似**。

当 posterior 已经很偏向 (H_1)，且距离上阈值 (A) 还很远时，

# [ L_{t+1}-L_t \approx I_a^+

D_{\rm KL}(p_1^a|p_0^a).
]

于是剩余时间近似

[
T_{\rm rem}
\approx
\frac{A-L_t}{I_a^+}.
]

这正是现在 (\tau_{\rm pred}) 的本质。

于是论文逻辑就完全不一样了：

现在：

[
\tau_{\rm pred}
\quad\text{是算法}.
]

以后：

# [ \boxed{ \tau_{\rm pred}

\text{Bellman policy 的 asymptotic / first-order approximation}.
}
]

这就有理论深度了。

Chernoff/KL 类策略在 sequential testing 中具有渐近最优性背景，但有限样本问题并不等价于简单最大化 KL，这也和你自己 Gate C 发现的“(I^+) 跨设计排序失败”完全一致。([arXiv](https://arxiv.org/abs/1203.4626))

------

# 四、底层量化也不能再是 `optimal_span(metric="chernoff")`

这一点甚至可以直接重构。

你现在是：

# [ Q^\star

\arg\max_Q C(Q).
]

这仍然是**静态量化器**。

真正的 sequential quantizer 应该依赖当前 posterior：

# [ \boxed{ Q^\star(\pi)

\arg\min_Q
\left{
c(Q)+
\mathbb E
[
V(\pi'(Q,Y))
]
\right}.
}
\tag{2}
]

也就是说：

### 当 (\pi\approx0.5)

系统可能需要一个“探索型”量化器，最大程度分开两种假设。

### 当 (\pi\to1)

量化器应该重点保护能够快速确认 (H_1) 的尾部证据。

### 当 (\pi\to0)

又应该偏向 (H_0) 的证据。

所以：

[
\boxed{
\text{最优 quantizer 应随 posterior 变化}.
}
]

这并不是凭空构造。Sequential detection 中的 optimal quantization 研究已经明确指出，最优量化规则应根据已经观察到的数据动态调整，而且 detector 与 quantizer 的联合设计会形成非凸问题。

因此你现在：

[
\text{uniform span}
\rightarrow
\text{Chernoff-optimal span}
]

其实只是第一阶段。

更深的一步应该是：

[
\boxed{
\text{belief-dependent Bellman-optimal quantizer}.
}
]

------

# 五、这里还能得到一个非常强、而且非常实用的理论：Blackwell pruning

这是我非常建议你做的。

假设两个 sensing/report actions (a,b)。

如果存在一个 stochastic channel (K)，使得

# [ p_h^b

p_h^a K,
\qquad h=0,1,
]

那么 (b) 是 (a) 的 garbling。

也就是说：

[
a \succeq_B b
]

在 Blackwell 意义下 (a) 比 (b) 信息更多。

如果同时

[
c(a)\le c(b),
]

那么可以直接证明：

[
\boxed{
b\text{ 永远不可能是 Bellman-optimal action}.
}
]

原因非常简单但很强：

使用 (a) 后，控制器完全可以人为再经过 (K)，模拟 (b) 的观测，然后执行原来基于 (b) 的全部后续策略。

所以 (a) 不可能比 (b) 差。

------

这条 theorem 的实际作用很大。

你现在大量：

[
(\text{UAV},b,\epsilon,s,P,Q)
]

组合可以先做 **information dominance pruning**。

例如：

[
b+1\text{ bit}
\to
b\text{ bit}
]

本身就是 coarse-graining；

更好的 BSC / 更高 success 的 reporting channel 也存在 degradation order。

以后 action space 不再用 Top-L heuristic 剪：

[
\text{deflection Top-L}
]

而是先用：

[
\boxed{
\text{Blackwell dominance exact pruning}
}
]

再进入动态优化。

这个理论价值远高于现在 NOMP 的 Top-L。

------

# 六、多目标以后，不应该再做 `tau 最大者优先`

这正是中层目前最浅的地方。

你的真正问题是：

[
\boxed{
\min_\pi
\max_q
\mathbb E_\pi[T_q]
}
]

同时满足总资源约束。

引入 epigraph (z)：

[
\min_{\pi,z}z
]

s.t.

[
\mathbb E_\pi[T_q]\le z,
\qquad \forall q,
]

[
\mathbb E_\pi[C]\le B.
]

给每个 fairness constraint 引入

[
\nu_q\ge0
]

以及资源价格

[
\lambda\ge0.
]

Lagrangian 为

# [ \mathcal L

z+
\sum_q\nu_q
(\mathbb E[T_q]-z)
+
\lambda(\mathbb E[C]-B).
]

对 (z) 极小化要求：

[
\boxed{
\sum_q\nu_q=1.
}
]

因此 (\nu) 落在 simplex 上。

于是 dual problem 变成：

[
\boxed{
\max_{
\nu\in\Delta_Q,\lambda\ge0
}
\left[
-\lambda B+
\sum_q
\inf_{\pi_q}
\left{
\nu_q\mathbb E[T_q]
+
\lambda\mathbb E[C_q]
\right}
\right].
}
\tag{3}
]

这一步非常重要。

原来的：

[
\text{“最差目标优先”}
]

现在变成了真正的**公平性对偶价格**

[
\nu_q.
]

资源紧张程度变成：

[
\lambda.
]

因此：

[
\nu_q
]

自动提高难目标权重，

[
\lambda
]

自动提高资源成本。

这就是一个真正的 weakly-coupled POMDP。

2025 年最新的 multi-action partially observable restless-bandit 工作采用的正是类似思路：多个不可观测子系统由共享预算弱耦合，Lagrangian relaxation 后分解成单个 POMDP，并通过双时间尺度更新价格。([arXiv](https://arxiv.org/pdf/2509.00415))

但你的不同点会很明显：

> 那类问题一般优化 reward；

而你的 local POMDP 是 **NP sequential detection + post-communication likelihood**。

# 七、这时真正的算法不再叫 information waterfilling

可以定义一个 **Bellman Value of Information**：

# [ \boxed{ \Delta V_{q,a}(\pi)

## V_q(\pi)

\mathbb E
[
V_q(\pi'\mid a)
].
}
]

它回答的不是：

> 这个 action 有多少 KL？

而是：

> **在当前 posterior 下，这个 action 最终能减少多少未来检测代价？**

然后定义净价值：

# [ \boxed{ G_{q,a}

## \nu_q\Delta V_{q,a}(\pi_q)

\lambda c(a).
}
\tag{4}
]

每周期真正做：

[
\max_{\mathcal A_t}
\sum_{(q,a)\in\mathcal A_t}G_{q,a}
]

s.t.

[
\sum c(a)\le B_t.
]

如果每目标只能选一个 action，这就是一个小型 multiple-choice knapsack。

这样整个算法成为：

[
\boxed{
\text{Bellman DP}
+
\text{dual prices}
+
\text{per-cycle exact knapsack}.
}
]

这已经完全不是“按 (\tau) 排一下”的算法复杂度了。

------

# 八、甚至可以进一步发展成 Detection Index

如果还想再拔高一层，可以研究一个很漂亮的问题：

对 target (q)，定义使 active 和 passive 恰好等价的临界价格：

# [ \boxed{ W_q(\pi)

# {\lambda: Q_q^{\rm active}(\pi,\lambda)

Q_q^{\rm passive}(\pi,\lambda)
}.
}
]

如果能证明：

> 随着 (\lambda) 增大，passive-optimal belief set 单调扩张，

那么该问题具有 **indexability**。

于是每周期甚至不需要 joint DP：

[
\boxed{
\text{优先激活 }W_q(\pi_q)\text{ 最大的目标}.
}
]

这会形成一个真正有辨识度的：

> **Belief-indexed multi-UAV active detection**

算法。

但这一条必须先证明 indexability，**不能提前宣称 Whittle index**。2025 年部分可观测多动作 restless-bandit 的研究也明确讨论了 index policy 及其局限，说明这里本身仍然有理论空间。([arXiv](https://arxiv.org/pdf/2509.00415))

# 九、还缺一个目前体系完全没有的东西：Fundamental Lower Bound

目前你大量实验只能说：

[
\text{算法 A 比 B 快}.
]

但不知道：

> **离理论最优到底还有多远？**

这也是“理论浅”的重要原因。

你已经有 post-communication likelihood，所以可以直接做 information-theoretic lower bound。

在 (H_1) 下，任意满足

[
P_{FA}\le\alpha,\qquad
P_{MD}\le\beta
]

的 sequential detector 都必须积累至少

[
\boxed{
\mathbb E_1
\left[
\sum_{t=1}^{T}
I^+_{a_t}
\right]
\ge
d(1-\beta\Vert\alpha),
}
\tag{5}
]

其中

# [ d(x\Vert y)

x\log\frac xy
+
(1-x)\log\frac{1-x}{1-y}.
]

同理在 (H_0)：

[
\boxed{
\mathbb E_0
\left[
\sum_{t=1}^{T}
I^-_{a_t}
\right]
\ge
d(1-\alpha\Vert\beta).
}
\tag{6}
]

如果所有动作满足

[
I_a^+\le I_{\max}^+,
]

马上得到

[
\boxed{
E_1[T]
\ge
\frac{
d(1-\beta\Vert\alpha)
}{
I_{\max}^+
}.
}
\tag{7}
]

甚至进一步定义 resource efficiency

# [ \rho^+

\max_a
\frac{I_a^+}{c(a)},
]

得到

[
\boxed{
E_1[C]
\ge
\frac{
d(1-\beta\Vert\alpha)
}{
\rho^+
}.
}
\tag{8}
]

这样以后实验终于可以画：

[
\frac{
T_{\rm proposed}
}{
T_{\rm lower\ bound}
}.
]

而不是只和 Greedy 比。

这才叫理论性能界。

Active sequential testing 文献本身就强调 information acquisition rate 和 optimal reliability 的基本下界，所以这一方向和经典理论是吻合的。([arXiv](https://arxiv.org/abs/1203.4626))

# 十、你现有三层应当这样“重新解释”

| 现在            | 新理论中的位置                                               |
| --------------- | ------------------------------------------------------------ |
| `tau_pred`      | Bellman policy 的高置信度一阶近似                            |
| `floor-cover`   | **single-stage / terminal-horizon Bellman 特例**             |
| Chernoff        | action screening / finite-horizon proxy / asymptotic exponent |
| (I^+)           | true-H1 下 LLR drift，不再承担跨设计优化                     |
| exact (P_D(n))  | terminal performance oracle                                  |
| NOMP refine     | 大动作空间下 per-cycle combinatorial approximate solver      |
| robust endpoint | 后续扩展到 robust Bellman kernel                             |
| MAPPO           | 只在 model mismatch 下近似 (V) 或 residual，不再负责主决策   |

这才是我认为最重要的收缩。

不是把模块删掉，而是把它们全部降级成：

[
\boxed{
\text{一个动态规划理论的特例、近似、上界或求解组件}.
}
]

# 十一、这套方案的算法深度也会明显提高

小规模可以做**真正的 exact oracle**。

因为你现在 quantization 后 observation alphabet 是有限的，而且 hypothesis 只有两个。

有限 horizon 下：

[
V_h(\pi)
]

可以用 POMDP 的 (\alpha)-vector recursion。

在 cost minimization 形式下，它可以写成：

# [ V_h(\pi)

\min_{k}
{
a_k\pi+b_k
},
]

即 piecewise-linear concave。

这意味着小规模甚至可以**不用 posterior grid**，直接维护 (\alpha)-vectors，得到 exact finite-horizon active detection policy。

大规模再做：

[
\text{per-target PBVI / adaptive 1-D DP}
+
\text{Lagrangian decomposition}
+
\text{knapsack scheduler}.
]

这就形成非常标准的：

[
\boxed{
\text{Exact theory}
\rightarrow
\text{structured scalable approximation}.
}
]

而不是现在：

[
\text{heuristic}
\rightarrow
\text{再补一个 empirical gap}.
]

# 十二、我建议暂时冻结其他所有扩展，只做这四个 Gate

这四个就足够判断新理论有没有价值：

**Gate D1 — Exact Bellman Oracle**

做 (Q=1)、小 horizon、小 action library。

比较：

[
\text{Bellman optimal}
,\quad
\tau_{\rm pred},
\quad
\text{Chernoff},
\quad
\Delta P_D.

看 detection delay gap。

**Gate D2 — Dynamic quantizer**

比较：

[
Q_{\rm fixed}^{Chernoff}
]

和

[
Q^\star(\pi)

的 Bellman-adaptive quantizer。

如果 adaptive quantizer 没提升，就不要继续量化器这条支线。

**Gate D3 — Multi-target dual decomposition**

做 (Q=2/3)：

[
\text{Exact joint Bellman}
]

vs

[
\text{dual decomposed Bellman}.
]

这里第一次真正报告：

[
\text{optimality gap}.
]

**Gate D4 — Fundamental-limit gap**

比较：

[
T_{\rm lower}
<
T_{\rm exact}
\le
T_{\rm proposed}
<
T_{\tau}.

如果 scalable policy 能长期保持例如接近 exact/lower-bound，而不是只赢 0.x pp，这条理论主线才真正成立。

## 最终建议

我现在反而不建议继续“完善你表里的三层”。

应该直接把那张表废掉。

新的核心不是：

[
\text{检测时间层}
+
\text{分配层}
+
\text{设计层}.
]

而应该是：

[
\boxed{
\begin{array}{c}
\textbf{Posterior-state controlled detection}\
\Downarrow\
\textbf{Bellman optimal stopping and experiment design}\
\Downarrow\
\textbf{Lagrangian fairness/resource decomposition}\
\Downarrow\
\textbf{Bellman value-of-information scheduling}\
\Downarrow\
\textbf{Blackwell pruning + exact/approximate POMDP solver}.
\end{array}}
]

这一次的提升不是“算法再复杂一点”，而是**把问题从静态优化升级成随机控制问题**。

最关键的是，它还能反过来解释你现在所有结果：

[
\tau_{\rm pred}
]

为什么有时有效；

[
I^+
]

为什么跨设计会失败；

Chernoff 为什么比 (I^+) 稳；

floor-cover 为什么静态情况下精确；

以及为什么预算松弛后主动策略和静态策略会重新趋同。现有 Gate B 已经显示了主动策略只在资源竞争明显时产生价值，这正是动态资源控制真正应该发挥作用的区域。

**我认为这才是值得继续投入的理论版本。** 如果这条成立，后面再把 OTFS probing、UAV movement、隐蔽探测作为 action dimension 加进去，系统会自然变复杂；而不是每增加一个物理模块，就再发明一套独立算法。
