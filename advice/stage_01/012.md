现在继续优化是有必要的，但**优化对象已经不应该再是 FRIDS-v2 的 index 本身**。

最新结果已经说明两件事：一方面，FRIDS-v2 在四个规模上达到 (J=3.32/3.45/3.60/3.53)，严格局部化、对偶一致、量纲和 token 记账都已经闭合；另一方面，F0-G5 又证明了 U2U 可靠性误差对当前 index 的影响很小，uniform robustification 本质上只是共同缩放，不改变 argmax，所以 Robust-FRIDS 是 NO-OP。

因此我建议**算法部分先冻结 FRIDS-v2**。下一步不再做 FRIDS-v3，而是把研究推进到一个更有理论价值、同时仍然紧贴当前算法的问题：

[
\boxed{
\text{FRIDS 在什么任务负载和通信条件下必然可行/不可行？}
}
]

这实际上比继续榨 1%–2% 的延迟更重要。

# 1. 下一步只做一个 Gate：F0-G6 可行性边界

当前已有的 load cut 是

# [ \rho(\mathcal S)

\frac{
\sum_{q\in\mathcal S}D_q^{\rm info}
}{
H\sum_i\max_{q\in\mathcal S}g_{iq}
}.
]

并已经证明：

[
\rho(\mathcal S)>1
\Rightarrow
\mathcal S\text{ 在剩余视界内不可全部完成}.
]

但现有场景：

[
\rho(\mathcal Q)\approx0.03\sim0.05\ll1,
]

所以根本没有进入信息容量受限区。

这意味着目前我们一直是在**很宽松的可行区域内部优化调度**。

下一阶段应该主动把系统推向边界。

# 2. 先把现在的 cut 升级成“最坏子集负载”

只看全体目标：

[
\rho(\mathcal Q)
]

其实还不够。

因为可能：

[
\rho(\mathcal Q)<1
]

但某一组弱目标：

[
\mathcal S\subset\mathcal Q
]

已经拥塞。

所以应该定义：

# [ \boxed{ \rho^\star

\max_{\varnothing\neq\mathcal S\subseteq\mathcal Q}
\frac{
\sum_{q\in\mathcal S}D_q^{\rm info}
}{
H\sum_i\max_{q\in\mathcal S}g_{iq}
}
}
]

这是下一步我最推荐增加的理论量。

然后：

[
\boxed{
\rho^\star>1
\Rightarrow
\text{当前任务集合信息论上不可按时完成}
}
]

而：

[
\rho^\star<1
]

只说明通过了必要条件，**不声称充分可行**。

这和你现在文档一贯的“必要条件不冒充充分条件”的风格是一致的。

# 3. 这个 (\rho^\star) 不是单纯暴力枚举，还能继续做理论

这是这里比较有创新性的地方。

定义：

# [ F(\mathcal S)

\sum_i\max_{q\in\mathcal S}g_{iq}.
]

对每个 UAV (i)：

[
f_i(\mathcal S)=\max_{q\in\mathcal S}g_{iq}
]

是单调次模函数，因此：

[
F(\mathcal S)
]

仍然是单调次模函数。

而需求：

# [ D(\mathcal S)

\sum_{q\in\mathcal S}D_q^{info}
]

是 modular。

于是判断：

[
\rho^\star>\lambda
]

等价于判断是否存在 (\mathcal S)：

## [ D(\mathcal S)

\lambda H F(\mathcal S)>0.
]

或者：

[
\min_{\mathcal S}
\left[
\lambda HF(\mathcal S)-D(\mathcal S)
\right]
<0.
]

由于：

[
\lambda HF-D
]

仍然是 submodular function，

理论上可以通过：

[
\boxed{\text{submodular minimization + binary search}}
]

求出 (\rho^\star)，而不是指数枚举所有 (2^Q) 子集。

这非常适合升级成一个正式定理：

> **Strongest Information-Load Cut / Bottleneck Subset Theorem**

这一条我认为比继续加一个调度 penalty 更有论文价值。

如果每个 UAV 无论选哪个目标都必然发送同一个：

[

]

bit token，那么简单写：

因为对固定 UAV (i)：

[

# [ \arg\max_q (J_{iq}-\lambda_i b_{\rm tok})

因此以后如果做通信定价，必须同时存在：

[
\boxed{\text{idle / no-report action}}
]

或者真正不同的：

[
b_{iq}.
]

否则“通信价格”只是数学装饰。

这点必须提前写死，避免再造一个无效模块。
