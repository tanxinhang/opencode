# 5. 我反而建议现在进一步“删掉” global normalizer Z

这是当前最值得做的最后一个算法优化，而且不是加模块，是**严格等价化简**。

当前 B0：

[
\lambda=0.
]

global-simplex 有

# [ y_q(t)

\frac{\exp\theta_q(t)}
{\sum_p\exp\theta_p(t)}.
]

B0 score：

# [ J_{iq}

\frac{y_qg_{iq}}{D_q+\epsilon}.
]

代进去：

# [ J_{iq}

\frac{1}{Z}
\frac{e^{\theta_q}g_{iq}}
{D_q+\epsilon}.
]

因为 (1/Z) 对所有 target 都相同，而且 B0 没有

[
-\lambda_jc_{ij}
]

这样的加法项，所以：

# [ \boxed{ \arg\max_qJ_{iq}

\arg\max_q
\frac{e^{\theta_q}g_{iq}}
{D_q+\epsilon}.
}
]

进一步直接进入 log 域：

[
\boxed{
\arg\max_q
\left[
\theta_q
+\log g_{iq}
-\log(D_q+\epsilon)
\right].
}
]

因此：

[
\boxed{Z\text{ 在 B0 中根本不需要计算，也不需要广播。}}
]

这非常重要。

现在代码仍把 global-simplex 的 (Z) 当作一个 networked scalar，并给 B0 收 10 bit/cycle。

但在最终的 **λ-free B0** 中，normalization 完全可以通过 scale invariance 消掉。

于是控制面可以从：

[
Qb_\pi+b_Z=8\times10+10=90
]

进一步变成：

[
\boxed{Qb_\theta=80\ {\rm bits/cycle}}.
]

更关键的不是省 10 bit，而是：

[
\boxed{
\text{不再需要任何 global reduction / global normalizer。}
}
]

这会让“分布式”定位明显更干净。

我非常建议把这个作为最后一次结构优化。

不是新增机制，而是：

> **Normalization-Free Distributed Deficit Pricing**

本质是对已有 B0 的**严格策略等价重参数化**。
