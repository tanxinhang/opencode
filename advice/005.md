# 4. 更值得注意：当前 stopping-tail “path-integrated bound”仍不够严谨

这一点比上面的 sample-max 更重要。

当前 `stopping_tail_verify()` 做的是：

[
\eta_r=(A_r(t)-D)_+,
]

然后逐路径计算：

[
\exp\left[
-\frac{\eta_r^2}
{2(V_r+b\eta_r/3)}
\right],
]

最后平均：

[
\beta+
\frac1R\sum_r
\exp(\cdots).
]

代码明确如此。

但是标准 Freedman inequality 并不能直接推出：

[
P(T>t)
\le
\beta+
E\left[
\exp
\left(
-\frac{(A_t-D)*+^2}
{2(V_t+b(A_t-D)*+/3)}
\right)
\right].
]

因为 (A_t) 和 (V_t) 本身是随机、历史依赖的。

也就是说，你成功修掉了：

[
\exp f(E[V])
]

的问题，但现在又变成了：

[
E[\exp f(A,V)],
]

这个也不是标准 Freedman 定理自然给出的形式。

### 更干净的 theorem 4.110 应该写成

对任意**确定性的**

[
\eta>0,\qquad v>0,
]

定义事件：

# [ E_t(\eta,v)

{T_q>t,,
A_q(t)-D_q\ge\eta,,
V_q(t)\le v}.
]

那么：

[
\boxed{
P_1(E_t(\eta,v))
\le
\beta_q+
\exp\left[
-\frac{\eta^2}
{2(v+b_q\eta/3)}
\right].
}
]

进一步：

[
\begin{aligned}
P_1(T_q>t)
\le&
\beta_q+
e^{-\eta^2/[2(v+b_q\eta/3)]}\
&+
P(A_q(t)-D_q<\eta)
+
P(V_q(t)>v).
\end{aligned}
]

这才是完全安全的“service → delay”结构界。

或者直接使用真正的 time-uniform curved boundary / supermartingale crossing result。Howard 等人的框架本来就是处理 sequential line crossing 的，因此比继续人为平均 pathwise Freedman exponent 更自然。([arXiv](https://arxiv.org/abs/1808.03204?utm_source=chatgpt.com))

### 我的建议

**删除“path-integrated stopping bound 是 theorem”这个主张。**

保留：

[
\text{deterministic joint-event Freedman}
+
\text{time-uniform crossing}
]

已经足够支撑你 Case-B 的理论定位。

这反而更稳。
