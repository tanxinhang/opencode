# 五、代码层还有一个小 P1：`airtime_admit()` 的 `t_air` 参数现在实际上没作用

当前：

```python
airtime_admit(
    offers_by_receiver,
    t_air,
    ...
)
```

但 admission 里面实际只检查：

[
\sum c_{\rm air}\le1,
]

而 `t_air` 没参与任何计算。

因为 caller 已提前计算：

[
c_{ij}=\frac{\tau_{ij}}{T_{\rm air}},
]

所以**当前结果没有错**。

但接口语义比较危险，因为未来有人可能：

```python
c_air = tau / old_t_air
airtime_admit(..., new_t_air)
```

函数仍然静默执行。

二选一即可：

```python
airtime_admit(offers_by_receiver, policy=..., tie_keys=...)
```

完全删除 `t_air`；

或者更物理地：

```python
airtime_admit(raw_tau_offers, t_air, ...)
```

由 primitive 内部计算 `tau/t_air`。

我更推荐后者，因为这样“共享 capacity primitive”才真正是 single source of truth。
