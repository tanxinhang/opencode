可以继续，而且我认为**值得继续**。但这次深度审计之后，我不建议再沿着“FRIDS-v2 上继续加修补项、再做 FRIDS-v3/v4”的方式推进。

当前项目已经到了一个明显的分水岭：

[
\boxed{
\text{下一步应该是“系统级重构与理论升格”，而不是“局部算法继续堆模块”}
}
]

更具体地说，我建议把整个研究重新收敛为：

[
\boxed{
\textbf{Communication-Constrained Task-Oriented Distributed Sequential ISAC Detection}
}
]

并把现有 FRIDS-v2 从“最终算法”重新定位为这个新框架中的**第一代 sensing-only reliable-information primal-dual scheduler**。下一代真正值得做的，不是加入更多启发式，而是推导一个**联合感知—通信容量约束下的双价格分布式算法**。

# 二、目前最大的项目级问题：实际上存在“两套系统”

这个问题比某个算法 bug 更严重。

`docs/SYSTEM_MODEL.md` 目前仍然把系统定义成“一融合中心 + RIS + 量化报告 + BSC/擦除 + expected-(P_D) selection”，其优化重点仍是报告集合选择与融合。

但当前 `SYSTEM_RESEARCH_REPORT.md` 已经明确把部署系统改成：

[
a_{i,t}=\pi_i(\mathcal I_{i,t}),
]

每架 UAV 只依据本地观测、成功收到的 U2U token 和本地历史决策，中央融合只作为离线 oracle。

更明显的是，论文 `submission.md` 现在标题仍然是：

> Exact Budgeted Soft-Information Fusion for UAV-ISAC under Correlated Reporting Losses

主体还是集中式线性融合、RIS、exact knapsack/max-min selection。

这意味着现在继续开发算法之前应该做一次：

[
\boxed{\textbf{Project Rebase}}
]

不是删历史代码，而是明确：

> **部署主系统是什么；哪些是 oracle；哪些只是历史实验；哪些属于 appendix。**

否则一个审稿人第一次阅读仓库会得到一个完全不同于最新 FRIDS 理论的系统。

# 三、当前真正值得保住的理论主干其实已经很清楚

整个项目积累了很多定理，但现在最值得保留的理论链只有六层左右。

第一层是**检测信息**。现在的 `action_kernels()` 已经不是简单 SNR proxy，而是把量化、BSC 和 detectable erasure 传播到有限字母概率：

[
P_h(Y=y\mid a),
]

然后得到精确 LLR：

[
\ell_a(y)=
\log\frac{P_1(y|a)}{P_0(y|a)},
]

以及

[
I_a^+=
D_{\rm KL}(P_1^a|P_0^a).
]

这是整个系统非常好的“任务信息货币”。

而这正契合 2026 年 goal-oriented communications 的发展：现在越来越强调通信资源应该由**下游推断/决策价值**而不是 bit throughput 驱动。最新 Nature Reviews Electrical Engineering 的综述也明确提出 task-level inference/decision metrics 应替代传统纯 bit-level metrics。([Nature](https://www.nature.com/articles/s44287-026-00303-9?utm_source=chatgpt.com))

第二层是**端到端可靠信息恒等式**：

# [ g_{iq}

s_{i,o_q} I_{iq}^{+},
]

在独立 detectable-erasure 条件下，这确实等于最终 owner 可见核的 KL divergence。Theorem 4.94 这部分逻辑是成立的。

第三层是**需求归一化 max-min relaxation**：

[
\max_{x,z} z
]

满足

[
\sum_i x_{iq}\frac{g_{iq}}{D_q}\ge z,\qquad
\sum_qx_{iq}\le1.
]

其静态对偶得到：

# [ J_{iq}

y_q\frac{g_{iq}}{D_q}.
]

这个比早期“边际收益”“Top-K”“经验权重”高一个理论层级，因为 index 是从公平服务 relaxation 的对偶结构里出来的。

第四层是**mirror descent**。现有 (O(\sqrt{T\log Q})) regret 本身没有问题，但要继续诚实限定：

[
\text{static/slowly varying relaxation tracking}
\neq
\text{global sequential-MDP optimality}.
]

第五层是**service-delay bridge**：

# [ \hat L_q(t)

\tilde A_q(t)+M_q(t),
]

用 Freedman-type martingale bound 把可靠服务过程与 stopping tail 联系起来。现在 P0.6 结果已经把 sample-derived (V)、stopped process、joint-event 等问题收紧，`gate_ok=true`。

第六层才是 capacity/phase boundary。

因此新的论文主理论完全不需要保留 100 多个“4.xx 定理”作为主叙事。

应该压缩为大约：

[
\boxed{
\begin{array}{ll}
T1 &: \text{Reliable task-information identity}\
T2 &: \text{Joint sensing-communication feasibility region}\
T3 &: \text{Exact bottleneck-cut certificate}\
T4 &: \text{Joint dual decomposition / local scheduling index}\
T5 &: \text{Distributed dual-message robustness}\
T6 &: \text{Reliable service }\Rightarrow\text{ stopping-delay bound}
\end{array}}
]

其他 RIS、NOMP、MAPPO、exact fusion、architecture switch 全部转 appendix/legacy。

这会比现在“理论很多”更像一篇成熟论文。

# 四、当前 FRIDS-v2 最大的理论缺口在哪里？

不是 (g=sI^+)。

不是 mirror descent 本身。

也不是 stopping rule。

真正的缺口是：

[
\boxed{
\text{FRIDS 的原始优化只显式写了“感知服务容量”，没有真正把通信容量写进同一个 primal。}
}
]

现在 P2.1 是：

[
\text{sensing action}
\rightarrow
\text{生成 token}
\rightarrow
\text{receiver overload}
\rightarrow
\text{random admission/drop}.
]

也就是说通信瓶颈仍然偏“环境约束”。

这就是整个系统可以真正拔高的地方。

# 五、我建议的新统一系统：Joint Sensing–Communication Capacity Model

对 UAV (i)、目标 (q)、感知动作 (a)，定义：

# [ I_{iqa}^{+}

D_{\rm KL}
\left(
P_1^{iqa}\Vert P_0^{iqa}
\right).
]

若目标 (q) 的 owner 是 (o(q))，U2U 投递成功率为

[
s_{i,o(q)},
]

则端到端期望可靠检测信息：

# [ g_{iqa}

s_{i,o(q)}I_{iqa}^{+}.
]

通信不再使用一个抽象 `400 bits/cycle` 即结束，而定义 token airtime：

# [ c_{iqa}

\frac{b_{iqa}}
{R_{i,o(q)}T_{\rm cyc}},
]

其中例如

[
R_{ij}
\le
W_{ij}\log_2(1+\gamma_{ij}).
]

这里特别要注意：Shannon rate 只能当上界。你当前 `airtime.py` 对这一点已经处理得比较诚实，同时已经有 token airtime、receive load 和通信 dual price 的基础实现。

然后把 FRIDS 的静态 relaxation 提升为：

[
\boxed{
\begin{aligned}
\max_{x,z}\quad & z\
\text{s.t.}\quad
&\sum_{i,a}
x_{iqa}
\frac{g_{iqa}}{D_q+\epsilon}
\ge z,\quad\forall q,\
&\sum_{q,a}x_{iqa}\le1,
\quad\forall i,\
&\sum_{i,q:o(q)=j,a}
c_{iqa}x_{iqa}
\le1,
\quad\forall j,\
&x_{iqa}\ge0 .
\end{aligned}}
]

这一个式子非常重要。

它第一次把：

[
\text{感知能力}
+
\text{通信可靠性}
+
\text{接收端容量}
+
\text{多目标公平性}
]

放进**同一个数学问题**。

# 六、由这个模型自然导出真正值得做的新算法：Dual-Bus / CA-FRIDS

给目标服务约束引入 (y_q)，给 receiver airtime constraint 引入：

[
\lambda_j\ge0.
]

Lagrangian 中与 (x_{iqa}) 有关的部分是：

## [ x_{iqa} \left[ y_q \frac{g_{iqa}}{D_q+\epsilon}

\lambda_{o(q)}c_{iqa}
-\mu_i
\right].
]

因此 UAV 的局部 best response 直接成为：

# [ \boxed{ (i,q,a)^*

## \arg\max_{q,a} \left[ y_q \frac{g_{iqa}}{D_q+\epsilon}

\lambda_{o(q)}
c_{iqa}
\right].
}
]

这是我认为最值得把整个算法升格的地方。

当前 FRIDS-v2：

# [ J^{v2}_{iqa}

y^{(i)}*q
\frac{g*{iqa}}{D^{(i)}_q+\epsilon}.
]

新算法：

# [ \boxed{ J^{CA}_{iqa}

## \underbrace{\pi_qg_{iqa}}_{\text{task-information value}}

\underbrace{\lambda_{o(q)}c_{iqa}}_{\text{communication opportunity cost}},
}
]

其中

# [ \pi_q

\frac{y_q}{D_q+\epsilon}.
]

这不是把一个 (\lambda) 拍脑袋加进去。

它是**联合 sensing–communication primal 的对偶 best response**。

这才应该叫真正意义上的算法拔高。

# 七、比“双价格”更加重要的架构创新：不要再 Full-Mesh Evidence Gossip

这里我认为甚至可以形成论文最有辨识度的一点。

当前部署逻辑仍然让很多 evidence token 在 UAV 间传播，以便每个 UAV 都维护自己的：

[
D_q^{(i)},\qquad y_q^{(i)}.
]

但 stopping decision 最终实际上落在 target owner 的：

[
L_{o(q),q}.
]

因此从充分信息的角度，其他 UAV 没有必要复制完整的其他节点 evidence history。

可以改成两个平面：

[
\boxed{
\text{Evidence Data Plane}
+
\text{Task-Price Control Plane}
}
]

Evidence plane：

[
i
\rightarrow
o(q)
]

UAV (i) 对目标 (q) 取得证据后，只把 evidence token 发给目标 owner。

Task-price plane：

owner (o(q)) 根据自己的真实 belief 计算：

# [ D_q(t)

[A_q-L_{o(q),q}(t)]_+,
]

以及任务价格：

# [ \pi_q(t)

\frac{y_q(t)}{D_q(t)+\epsilon}.
]

然后广播一个非常短的：

[
\boxed{\pi_q(t)}
]

receiver (j) 再广播：

[
\boxed{\lambda_j(t)}.
]

于是每架 UAV 不需要同步全局 belief，只需要最新的：

[
{\hat\pi_q}*{q=1}^{Q},
\qquad
{\hat\lambda_j}*{j=1}^{K}.
]

自己的 (g_{iqa}) 是本地可计算量。

最终：

# [ a_i(t)

## \arg\max_{q,a} \left[ \hat\pi_qg_{iqa}

\hat\lambda_{o(q)}c_{iqa}
\right].
]

我建议把这个架构叫做类似：

[
\boxed{\text{Task-Oriented Dual Bus}}
]

而不是“总线”作为计算机类比停留在比喻层面。

这里已经变成数学上有意义的：

> **只传播决策所需的对偶充分信息，而不是复制所有原始 evidence。**

这个思想与当前 goal-oriented communication 的发展方向高度一致：通信内容由下游任务需要决定，而非“能传多少就传多少”。([Nature](https://www.nature.com/articles/s44287-026-00303-9?utm_source=chatgpt.com))

而 2025/2026 的 goal-oriented MAC 已经开始使用 distributed belief/public information 来减少不必要传输，所以单纯“belief-aware MAC”本身已经不够新。([帕多瓦大学研究院](https://www.research.unipd.it/handle/11577/3568558?utm_source=chatgpt.com))

你的差异应该放在：

[
\boxed{
\text{sequential detection information}
+
\text{dual sufficient messaging}
+
\text{hard receiver capacity}
+
\text{stopping-time theory}
}
]

上。

# 八、这个 Dual-Bus 还能把现有 Theorem 4.109 大幅简化

现在 action-invariance bound 很复杂：

# [ E_i

V_{\max}\epsilon_y
+
\epsilon_v
+
\epsilon_y\epsilon_v.
]

而新架构直接传：

# [ \pi_q

y_q/(D_q+\epsilon).
]

于是 ideal score：

# [ J_{iqa}

\pi_qg_{iqa}-\lambda_jc_{iqa}.
]

若：

[
|\hat\pi_q-\pi_q|
\le\varepsilon_\pi,
]

[
|\hat\lambda_j-\lambda_j|
\le\varepsilon_\lambda,
]

则直接有：

[
\boxed{
|\hat J_{iqa}-J_{iqa}|
\le
g_{\max}\varepsilon_\pi
+
c_{\max}\varepsilon_\lambda.
}
]

定义 ideal top-1 margin：

# [ m_i

## J_{i,a^*}

\max_{a\ne a^*}J_{ia}.
]

只要：

[
\boxed{
m_i>
2(
g_{\max}\varepsilon_\pi
+
c_{\max}\varepsilon_\lambda
),
}
]

就保证：

[
\hat a_i=a_i^*.
]

这个定理非常有用。

它进一步可以直接反推出**控制 token 最少需要多少 bits**。

也就是说：

[
\text{action margin}
\rightarrow
\text{允许 price error}
\rightarrow
\text{price quantization bits}.
]

这就把：

[
\boxed{
\text{算法稳定性}
\leftrightarrow
\text{通信开销}
}
]

真正通过一个数学式连接起来了。

这比简单优化 LLR token 从 5-bit 到 6-bit 有意义得多。

# 九、现有 (\rho_I^\star) 理论还可以进一步“拔高”

当前最强 information cut：

# [ \rho_I^\star

\max_{\emptyset\ne S\subseteq\mathcal Q}
\frac{
\sum_{q\in S}D_q
}{
H\sum_i\max_{q\in S}g_{iq}
}.
]

数学想法很好。

但是当前 `feasibility.py` 的所谓 Fujishige-Wolfe 实现，内部实际上用了 SLSQP 解凸组合权重，还有 iteration/stall cutoff。

所以：

> “一般的 submodular minimization 在多项式时间存在”

是数学事实；

但：

> “当前程序就是一个 certified exact polynomial SFM solver”

目前还不够严谨。

这里反而存在一个非常漂亮的、可以针对你这个特殊 (F(S)) 做出的改进。

对 UAV (i)，把所有不同的 (g_{iq}) 排序：

[
0=\gamma_{i0}
<
\gamma_{i1}
<\cdots<
\gamma_{iL_i}.
]

则：

# [ \max_{q\in S}g_{iq}

\sum_{\ell=1}^{L_i}
(\gamma_{i\ell}-\gamma_{i,\ell-1})
z_{i\ell}(S),
]

其中：

# [ z_{i\ell}(S)

1
\iff
\exists q\in S:
g_{iq}\ge\gamma_{i\ell}.
]

于是：

[
\lambda HF(S)-D(S)
]

可以转换成带 auxiliary OR nodes 的**minimum-weight closure**问题。

而 minimum closure 可以精确归约为：

[
\boxed{s-t\text{ min-cut}}
]

求解。

也就是说，现在的泛化 SFM 可以替换为：

[
\boxed{
\text{Structure-Exact Bottleneck Cut}
}
]

优点很明显：

[
\text{SLSQP+stall numerical oracle}
\rightarrow
\text{graph min-cut certificate}.
]

甚至进一步可以使用 parametric min-cut 来寻找 (\lambda) breakpoint。

这个理论升级我认为非常值得做，因为它不是性能调参，而是直接把一个当前“理论上 exact、实现上近似”的模块变成**结构上 exact + 工程上快**。

# 十、更进一步：(\rho_I) 和 (\rho_C) 不应该成为最终容量理论

P2 现在用两个轴：

[
\rho_I^\star,\qquad\rho_C.
]

非常适合解释：

> 是 information 不够，还是 communication 搬不动。

但它们最终应该降级成**diagnostic cuts**。

因为真实系统会有：

[
\text{sensing allocation}
\leftrightarrow
\text{receiver capacity}
]

耦合。

最完整的容量基准应该就是前面的 joint LP：

# [ \mathcal C_{\rm SC}

\left{
D:
\exists x,,
Gx\ge D/H,,
Ax\le1,,
Cx\le1
\right}.
]

于是以后真正的 envelope 不应该是简单：

[
\rho_I<1,\qquad\rho_C<1.
]

而是：

[
\boxed{
D/H\in\mathcal C_{\rm SC}.
}
]

然后再定义：

# [ \lambda_{\rm joint}

\max{
Q/K:
\text{joint relaxation feasible}
}.
]

最后才有：

# [ \Gamma_{\rm sys}

\frac{
\lambda_{\rm deployed}
}{
\lambda_{\rm joint}
}.
]

这才是真正有系统意义的：

> **分布式部署算法距离联合 sensing-communication capacity relaxation 还有多远？**

比原来的：

[
\Gamma_{\rm dual},
\qquad
\Gamma_{\rm envelope}
]

理论层次更高。

# 十一、为什么我反而不建议回到“轨迹 + 波束 + 功率 + MAPPO”

最近 multi-UAV ISAC 的这一类研究已经非常拥挤。

例如 2026 年 8 月刚上线的多 UAV ISCC 工作，就已经同时优化 task scheduling、beamforming 和 UAV trajectory，并采用 max-min radar mutual information 做 sensing fairness。([科学百科](https://www.sciencedirect.com/science/article/abs/pii/S1874490726002971?utm_source=chatgpt.com))

新的 UAV-assisted ISAC 论文也还在继续做 coalition、auction、resource allocation 等方向。([科学百科](https://www.sciencedirect.com/science/article/abs/pii/S1389128626005402?utm_source=chatgpt.com))

如果现在把本系统改回：

[
\text{trajectory}
+
\text{beamforming}
+
\text{power}
+
\text{MAPPO/SCA},
]

不但系统重新发散，而且现有最有价值的：

[
I^+
\rightarrow
\text{distributed service}
\rightarrow
T_q
]

理论链会被淹没。

因此轨迹、RIS、NOMP、MAPPO 都建议改成：

[
\boxed{\text{optional extension / baseline / oracle}}
]

而不是论文身份。

# 十二、物理层仍然必须补，但只补“最小物理闭环”

这里是当前另一个明显短板。

`build_distributed_scenario()` 目前仍是：

- sensing SNR 从随机 dB 区间抽；
- BSC flip 随机抽；
- success 在随机区间抽；
- U2U success matrix 再随机生成；
- DD domain 主要通过 sinc² fractional-bin leakage hook 进入。

所以当前 FRIDS 是一个不错的：

> distributed sequential detection network

但作为：

> **UAV-OTFS-ISAC**

物理身份还不够强。

不需要完整 IQ transceiver。

只需要补一层：

[
(\mathbf p_i,\mathbf p_q)
\rightarrow
\mathrm{SNR}^{sen}*{iq}
\rightarrow
(\tau,\nu)\text{ DD leakage}
\rightarrow
P_h^{iqa}
\rightarrow
I*{iqa}^{+}
]

同时：

[
(\mathbf p_i,\mathbf p_j)
\rightarrow
\gamma_{ij}^{comm}
\rightarrow
R_{ij},s_{ij}
\rightarrow
c_{ij},g_{iq}.
]

尤其要坚持：

[
\boxed{
\text{sensing channel}
\neq
\text{communication channel}
}
]

两者可以共享 geometry，但不能把 sensing SNR 与 U2U SNR 强行绑成同一个 path-loss 模型。

这符合基本通信/感知物理原则。

如果这层不补，我建议最终论文标题弱化 “OTFS”；如果补完，就可以比较有底气保留 Multi-UAV OTFS-ISAC。

# 十四、我建议的新项目主线

接下来只建议做下面这一条路线，不要同时再开五个方向：

1. **P2.1a：认证修复。** 修 conditional count、simultaneous CI、真实 geometry seeds、censoring、整数/airtime hard capacity、`UNCERTAIN` 归类；FRIDS-v2 不动。
2. **P2.2：把现有 FRIDS-v2 的真实 phase diagram 跑出来。** 真正确定 information-limited、communication-limited、mixed、coordination-limited 分别在哪里。只有这一阶段才能回答“有没有 algorithm gap”。
3. **P3.0：System Rebase。** 重写唯一 `SYSTEM_MODEL`，deployment 只保留 distributed sequential detection；central exact DP/KKT fusion、NOMP、MAPPO、RIS 移到 oracle/legacy；同步修改 package identity 和论文身份。
4. **P3.1：Joint Capacity Theory。** 建立 sensing + receiver-airtime 联合 LP；(\rho_I,\rho_C) 作为 cuts；实现 structure-exact min-cut bottleneck oracle。
5. **P3.2：Dual-Bus / CA-FRIDS。** owner 维护 task price，receiver 维护 congestion price；evidence 只发 owner；广播 (\pi_q,\lambda_j)；推导联合对偶 index 和 quantization/staleness action-invariance theorem。
6. **P3.3：Minimal Physical Closure。** UAV geometry → sensing SNR/DD kernel；U2U geometry → rate/PER/outage；不加入轨迹优化，不加入 RIS 优化，不加 RL。
7. **P3.4：唯一生死 Gate。** 在 uncongested 区 CA-FRIDS 相比 v2 回退不超过约 2%；在 communication/mixed boundary，若可行负载扩大 ≥10% 或 worst-target delay 改善 ≥5%，且 hard airtime、(P_{FA})、(P_{MD}) 同时通过统计认证，则升级为主算法；否则保留 FRIDS-v2，把 joint capacity + phase law 作为论文主贡献。

这一套有一个很重要的好处：

> **新算法失败也不会导致论文失败。**

如果 Dual-Bus 没有明显提升：

[
\Gamma_{\rm sys}\approx1,
]

那就证明：

> FRIDS-v2 已经接近 joint sensing-communication relaxation boundary。

本身就是很强的负结果。

如果提升明显，则：

> joint communication dual 是现有 FRIDS 缺失的真正结构。

两边都有研究价值。
