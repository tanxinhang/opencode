## 1. 系统概述

分布式 UAV-OTFS-ISAC 选择性软信息融合检测系统:`M` 个 UAV 对 `Q` 个目标产生 OTFS DD 域矩匹配高斯证据 `(mu0, mu1, Sigma0, Sigma1)`,经 `b_i` 比特量化、BSC 翻转(概率 `epsilon_i`)与接收律 `gamma` 擦除后,由融合中心用偏转最优线性得分融合,得到目标检测概率 `P_D = Phi((shift - z_FA)/sigma)`。感知与报告链路物理模型、资源账本见 `SYSTEM_MODEL.md`。

**部署模型(2026-08-17 纠偏,advice/005)**: 在线部署为**通信受限分布式**—— 每架 UAV 仅用信息集 `I_{i,t}`(本地观测 + 成功送达的 U2U token + 自身历史)与局部 belief `L_{i,q,t}` 决策(`a_{i,t} = π_i(I_{i,t})`),U2U 协调轮次 ≤ 2,节点级预算,分布式 owner/证据 token/冲突价格;集中融合中心保留为**离线审计 oracle**(Gate F0,见 §4.8)。

**当前唯一主问题(advice/006 收敛,2026-08-17)**: 在通信受限、无中心的多 UAV 协同检测系统中,紧凑证据交换和局部任务决策能否在 UAV/目标规模增加时维持可靠检测?其余(FOV/安全距离/动态 owner/移动/coalition/稀疏拓扑)全部冻结为模型假设与后续扩展;本轮只回答"当前系统自身能扩展到哪里"(Gate F0-S,见 §4.9)。

## 2. 优化问题与最优解

### 2.1 优化函数(目标与约束)

**离线审计形式**(集中式 oracle,纠偏后不作部署算法;`SYSTEM_MODEL.md` §1 与 §7):预算约束下的**字典序最大最小(lexicographic max-min)期望检测概率**:

```
maximize     lexmin_{q}  E[ P_D(q; {p_qr, b_qr}) ]       (期望对擦除取)
subject to   sum_q sum_{r in S_q} (p_qr + b_qr) <= B     (比特成本预算)
             p_qr in {0..P_max},  b_qr in {0..B_max}
```

鲁棒变体: 每个 `(power, bit)` 选项在干净通信点与最坏端点 `(flip_hi, success_lo)` 评估(引理 4.70 证明端点即通信模糊矩形最坏情形)。

**部署形式(P-DIST,advice/005 §12;`SYSTEM_MODEL.md` §1.1)**: 无中心协调器,每架 UAV 用信息集 `I_{i,t}` 决策:

```
min_{pi_1..pi_K}  max_q E[T_q]
s.t.  P_FA,q <= alpha_q,   P_MD,q <= beta_q
      a_{i,t} = pi_i(I_{i,t})           (信息约束:禁止全局量)
      b_{i,t} <= B_{i,t},  e_{i,t} <= E_{i,t},  t^comp_{i,t} <= T_cycle
      R_coord <= R_max                 (每周期协调轮次 <= 2)
```

### 2.2 推荐最优解(按规模)

| 层 | 规模 | 最优解 | 模块 | 性质 |
| --- | --- | --- | --- | --- |

| 审计 | 小-中规模(精确) | **鲁棒联合功率-比特精确 DP**(最坏端点) | `robust_joint_power_bit` | 精确最坏情形分配 |

## 3. 算法架构

**部署流水线(advice/005 §19,无融合中心、无全局在线优化器)**: OTFS 本地感知 → 局部任务 belief(`L_{i,q,t}` 逐观测 LLR 累积)→ 紧凑 U2U token(证据 + intent,≤2 轮)→ **FRIDS 分布式调度**(目标检测缺陷 `D_q=[A*−L]+` 驱动对偶价格 `ν_q`,`J=ν_q·g_{iq}` 选择感知动作;信息可行性证书防 resource sink)→ 局部感知动作 → 新观测闭环。

**审计流水线**(集中式,离线): 场景构建 → 前端(期望 `P_D`/贪心)→ 分配求解(精确 DP 或 NOMP 贪心+refine)→ 融合(KKT 闭式)→ gate 验证链(scripts/run_*_gate.py → results/*.json → verify_paper_numbers)。详见 `SYSTEM_MODEL.md` 与 `RUN_MATRIX.md`。

### 4.5 检测感知量化与信息梯度(advice/001.md 驱动,2026-08)

- **Gate C(设计度量正确性,48 随机链路 × 11 span,Part A)**: `argmax I+`(KL 均值漂移)的 span 在 **62.5%** 实例使精确 `P_D(4)` 低于最优 >1%(粗量化集中 H0 质量,经 BSC 后 KL 反而高,但精确 `P_D` 不跟随);Chernoff 仅 **14.6%** 失败 → 设计度量层级 `精确 P_D > Chernoff > I+`;advice 的"KL 最大化量化"在该设计族内是回归(4σ 默认 span 对 `P_D` 已近最优)。

- **精确分配升级(floor-cover 定理,FORMAL_PROOFS 4.91)**: `maxmin_pd_allocation` 用最小成本覆盖求解最差目标 max-min `P_D` 分配,无凹性/单调性假设、多项式复杂度;Gate C 实测与穷举 **100% 一致**(0.794),可扩展到大场景;I+ 注水降级为对照启发式(4.7% 界为实测)。**NP 可容许性(4.92)**: 真实 `P_D(n)` 比特单调(细化链),但网格统计量非精确 LLR,实现违反 ≤ 0.008 由 `verify_pd_bits_monotonicity` 如实报告。

### 4.6 Belief-Bellman 主动控制主线(advice/003.md 驱动,2026-08)

- **Gate D1(advice/003 "最重要的下一步",Q=1,R=3,b=1..4,P=2 档,H=B=6,c10=c01=20)**: 显式预算状态精确有限视界 Bellman `V_t(pi,B)`(`budget_bellman_value`,状态 = 后验 log-odds × 剩余预算,观测扣减预算、预算耗尽强制停止)对比 τ_pred / Chernoff / 一步贝叶斯前瞻(dpD) / static floor-cover。24 动作经 Blackwell 剪枝至 11;**诚实判定: 精确 Bellman 相对最优 myopic(dpD,总代价 5.062)仅 +0.4%(B=6),预算扫描 B=2..8 全部 ≤2.7%,未达 5% 实质性门槛 → 按 advice 决策规则,单目标尺度"Agent 化"不值得做,不进入 value 蒸馏第二步**;但 Bellman/dpD 相对信息型 myopic(τ_pred/Chernoff/c,6.2-6.5)稳定优势 15-20%,瓶颈在信息型调度层而非多步前瞻。`results/bellman_detection_gate.json` part_d1b。
- **Gate D1c(Reflexion 数学化,advice §4)**: 残差自适应控制器 `residual_adaptive_policy` 对每次观测标准化 Bellman 残差 `r_t = c + V(l_{t+1}) - V(l_t)` 于 H0/H1 两个模型条件分布,累积均值统计量 `tau = min(|mean_0|,|mean_1|)`(收敛估计,单假设流下正确模型 τ→0): **正确模型 τ=0.038 不触发;success 0.95→0.5 擦除失配 τ=0.666 触发并切到 robust/explore;flip-only 失配不触发(如实报告的统计量局限,LLR 原子幅度未变)**;适配后实现代价 ≤ naive Bellman(容忍内)。`results/bellman_detection_gate.json` part_d1c。
- **分配-时间闭环(advice §12,docs 待办 §27.6)**: 在 Gate B 的逐周期预算循环中加入预算 Bellman G 值调度(`G = V(l,b) - [c + E V(l+llr,b-c)]`,每周期按剩余预算 + 当前后验重分配): **负结果 —— 最差目标 T 3.50 vs active(τ_pred)2.08,增益 -40.7%,`bellman_passed=False` 如实报告**;价值型调度的停止经济学(代价目标)与 Gate B 的 P_D 阈值目标不一致,价值代理(I+ 漂移)高估进度,确认 Gate D1b 判定在逐周期闭环层面同样成立 —— 多目标预算耦合不是 Bellman 占优场景,除非价值函数直接嵌入 P_D 阈值目标(阶段 24 由此校正目标,见 §4.7)。`results/active_detection_gate.json` closed_loop。
- **Blackwell 剪枝三级(advice §8)**: 第一级 exact dominance(LP,已有)+ 第二级 `value_bound_prune`(精确动作消去: 续估值从未优于终止代价的动作在每步被剪除,与无剪枝值函数逐位一致,零信息内核全步剪除)。第三级 approximate search 未做。

## 4.8 分布式信息审计主线(advice/005.md 驱动,2026-08-17,Gate F0)

## 4.10 目标竞争审计与分配修复(advice/007 驱动,2026-08-17,Gate F0-A)

F0-S 判定"检测层延迟增长"后,F0-A **不改任何机制**,只在同一 paired 规模 (6,3)→(8,4)→(12,6)→(16,8) 上逐周期记录 5 个诊断量(4 seeds × 400 runs,`results/competition_audit_gate.json`,~11 min):

| --- | --- | --- | --- | --- | --- | --- | --- |
| (6,3) | 5.34 | 0.417 | 4.0 | 6 | 0.442 | 0.05% | 4.7e7 |
| (8,4) | 4.16 | 0.297 | 5.5 | 8 | 0.300 | 0.15% | 9.7e6 |

- **诊断结论(Case 2+3 并存)**: r_min 随规模 −44%(目标服务率下降)、H_idle +31%(空闲拉长)、ρ_alloc −62%(紧迫度→分配的映射瓦解)、n_max=K(每周期全部 UAV 集中同一目标)—— **starvation + over-concentration 双签名**。
- **关键发现 1(价格惰性,数理)**: 带内 dual-G 增益为 1e5–1e9 量级(停止带 1e9 终端),任何 O(1) 加法价格/age 在数学上不可比 —— **distort 率 ≈0.1%:拥塞价格几乎从不改变选择,ψ 事实上是死代码**;代价是加法价格需要**有界决策变量**(归一化)。
- **关键发现 2(easy-target bias,机制)**: 带内增益 ≈ 一步穿越概率 × 1e9 —— 第一周期弱目标 q0 增益 **−1.0**、易穿越目标(q4/q2/q5)**+2.2–2.5e7**;索引按"立即可解决性"排序,**系统性低估需要帮助的难目标**,min-max 价值语义在 1e9 尺度下丢失(ρ_alloc 下降的根因)。
- **修复实验(一次只改一个量,`results/allocation_fix_gate.json`,~46 min)**: 原样 age 项与 ψ 曲率(γ=1.5/2)**均无效**(单位失配);**归一化索引**(每 UAV 每周期按本地增益尺度归一,价格/age 恢复有效)后:**(12,6) 价格 η=1 → J 5.56→4.94(−11%,P_MD 0.067 达标)**,(16,8) 所有配置均无法改善(J≈5.7)→ 最大档 worst-target 由**单个内在困难目标**决定(16/8 中 q7 的 e1=5.68 独大,其余 ≤4.2;12/6 为弱目标 q0=5.61)—— 按 advice §9,该增长是目标难度分布主导,**不是分配可修复的**。
- **理论支撑**: (i) 加法协调项有效性 ⟺ 决策变量有界(归一化定理,实测 distort 0.1%→归一化后 age/价格生效);(ii) 并发观测边际价值 ∝ n⁻²(延迟 ~ A/(n·I⁺),第 n 个观测者边际收益 ~ (A/I⁺)·n⁻²)⇒ 凸价格(γ≥2)是正确曲率,但必须先解决单位;(iii) age 项 = 任务级 AoI(检测 AoI,token 的 t_stamp 语义)—— 顺序检测真正怕的是 belief 信息流的长空隙。
- **通信/感知原则(全程未违反)**: 修复保持在 19-bit token 协议内(无协议变更);age/价格建模感知能量机会成本(n 个 UAV 同目标 = n× 感知能量)与检测信息下界(`E_1[ΣI⁺] ≥ d(1−β‖α)` 不变,belief 更新未动)。
- **创新点**: 检测-AoI 调度项(归一化 dual-G + age)、ρ_alloc 分配质量度量、逐周期 regret 分解(离线审计)、"加法价格⟺有界决策变量"的单位失配诊断 —— 均为 F0 骨架上的单标量扩展,非新系统模块。

## 4.12 Token 保真度审计与 F0-D 方法学修正(2026-08-17,Gate F0-E)

F0-D 曾将 (16,8) dec gap 的 22.3% 归因于弱目标证据量化。F0-E 用三个有理论支撑的 token 设计在同一 19-bit 预算内测试该杠杆(通信原则:协议不变、零额外流量;`results/token_fidelity_gate.json`,400 runs × 3 seeds):

| 设计 | 理论依据 | (12,6) ΔJ | (16,8) ΔJ |
| --- | --- | --- | --- |
| Lloyd-Max R4(按目标等权) | 质心条件=每 bin 无偏,H1 加权保漂移 | +0.40 | +0.07 |
| μ-law R4 | 压扩近零细分(经典语音压扩用于检测 token) | +0.98 | +0.56 |
| uniform R4(范围匹配) | 量化器范围应匹配源支撑 | +0.06 | −0.08 |
| **L̂ 5→10 bits(预算内重分配)** | F0-A 证明 u/r/χ(6 bits)为死载荷;率失真 D(R) | −0.14(重校准) | −0.02(重校准) |

- **负结果(干净)**: 码本重设计 ≤±0.1 周期;**L̂ 提至 10 bits(1024 级、近精确)在 16/8 仍无增益(−0.2%)** —— 量化速率不是瓶颈;F0-D 原"量化份额 22.3%"被证明是 **B(全消息)模式未归一化索引的混淆伪影**。
- **F0-D 方法学修正(2026-08-17)**: 分解的 B/cent 参考改用与主线相同的归一化索引(cent 为无价格全局参考 η=0、B 保持部署价格 η=1)。修正后 (16,8) 最难目标(弱目标): **iso 29.3% / comp 34.5% / dec 36.2%**(Case C 不变);dec gap 成分: **投递/局部 +40.6%、量化 −4.4%**(中值量化漂移放大的已知伪影方向)→ **(16,8) 的 dec gap 是投递/协调受限,不是证据保真度**。
- **理论**: (i) 中值量化每 bin 误差随 bin 内不对称性有偏,5-bit 均匀网格下弱目标小原子漂移被放大(解释负 quant share);(ii) 率失真:10-bit 已近精确而 J 不变 ⇒ 损失在传输路径(投递失败、意图 1 周期滞后),不在编码;(iii) F0-A 死载荷诊断(u/r/χ 算法从不读取)支持预算内重分配,但重分配收益同样 ≈0。
- **下一步(数据驱动)**: (16,8) 剩余可优化空间在 **投递/协调层** —— 冻结协议允许但未用的 R_coord=2 第二轮(意图新鲜化)、预算内投递可靠性(χ 字段语义化)、或投递冗余;Q/K 负载可行性区域(comp 34.5%)并列候选。

## 4.13 投递/协调审计与尺度自适应价格(2026-08-17,Gate F0-F)

F0-E 关闭 token 保真度方向后,剩余 dec gap 定位在投递/协调层。本轮先分解、后优化(冻结默认保持):

**dec gap 分解((16,8) full_message 参考,配对,`results/dec_gap_decomposition.json`)**: 完美投递使 J 从 6.23 → 5.04(−1.2 周期,**投递是主导项**,物理层受限);**新鲜意图(R_coord=2,协议允许)反而恶化** — full_message +2.0、主线 +2.5(价格变新鲜后过度驱散,伤害弱目标集中服务)→ **负结果**。

**价格尺度扫描(归一化主线,`results/price_scale_sweep.json`)**: (12,6) 最优 η*=1.0(J 4.92),(16,8) 最优 η*=0(J 5.69)—— 拥塞价格的最优尺度随 K 塌缩。

**尺度自适应价格(正式,500×4,`results/scale_adaptive_price.json`)**: (12,6) η=1 → **J 4.935**(不变,P_MD 0.067 达标);(16,8) η=0 → **J 6.014 → 5.680(−5.6%,P_MD 0.054 达标,r_min 0.152→0.224)**。
